## 4. 缺陷清单

### D1（P1，已修复）朋友圈自动动态事件载荷不一致

- 位置：`engine_progress.js:693` emit `{moment: ...}`，UI `ui/08_moments.js:162` 期望 moment 对象
- 表现：`Cannot read properties of undefined (reading 'slice')`，120s 长跑出现 3 次
- 修复：引擎统一 emit moment 对象；UI 兼容 `{moment}` 包装并做空值/类型防御
- 验证：60s 长跑 0 问题；回归 63/63、剧情 294/294

### D2（P1，已修复）覆盖率门禁在当前 Node 崩溃

- 位置：`package.json` devDependencies `c8 ^12.0.0` → `yargs@18`（ESM-only，要求 Node ≥22.12）
- 表现：`ERR_REQUIRE_ESM ... node_modules/yargs/index.mjs`
- 修复：`c8 ^10.1.3`（yargs 17，CJS）
- 验证：`test:cov` 通过，8 个文件覆盖率均 ≥60%

### D3（P1，未修复，部署侧）线上版本落后

- 线上 v0.8.4，仓库 v0.8.7；线上 bundle 缺失 18 条新事件
- 根因：`e458ca4` 删除全部 GitHub Actions 工作流，自动部署停止
- 现状：本环境无 `hf` CLI / `HF_TOKEN` / SSH 私钥，9443 不可达，无法代部署

### D4（P2，未修复）GitHub Pages 发布开发态

- 原 `deploy.yml` 上传仓库根目录（非 `dist`），首载串行请求 61+i18n 脚本
- 若恢复部署工作流，应改为构建后上传 `dist`（本轮已提供 `.nojekyll` 生成）

### D5（P3，环境限制）`npm audit` 不可用

- 镜像 `mirrors.huaweicloud.com` 返回 405；建议在支持 audit 的 registry 或本地执行

### D6（P3，观察）dev 依赖警告

- `c8` 传递依赖 `glob@10.5.0` 有已知漏洞警告，仅影响测试工具，不进入运行时产物

### D7（P3，覆盖不足）仅 Chromium

- 未覆盖 Firefox / WebKit（Safari），建议发布前补一轮真机/多浏览器抽测

### D8（P3，观察）CSP 强度待复核

- 存在 1 处 CSP 配置，建议做一次策略审计（是否允许 inline/style、unsafe-eval 等）
