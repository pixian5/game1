# v0.3.8：i18n 深化（B1-b）

> 2026-10-24 10:36 · CodeArts

> 本版为《下一步开发计划（v0.3.3 之后）》**阶段 B 的 B1 第二步（B1-b）**。

## 一、目标

在 B1-a（框架 + 固定文案）基础上：暴露全局 `t()`、增加英文骨架包、并把**带变量**的
UI 文案改为模板插值（选最集中的存档模块作示范）。

## 二、改动

1. **全局 `t()`**：`i18n/index.js` 在 `window.t = I18N.translate`（浏览器）/`globalThis.t`
   （Node）暴露简写，调用处可写 `t('已保存到 {slot}', {slot})`。
2. **中文模板键**：`i18n/zh-CN.js` 增 17 个带 `{var}` 的模板（已购买/已送出/心情/连胜奖励/
   完成约会/存档读档导入/进入线/观赏自动选/碎片/心声等）。
3. **英文骨架** `i18n/en-US.js`（新增）：示范 21 条译文（含模板，如
   `'已保存到 {slot}': 'Saved to {slot}'`）；未收录 key 由 `translate` 回退中文。
4. **示范改造** `ui/20_saves.js`：5 处带变量 toast 改为 `t('模板', {vars})`
   （已保存到/已读取/已导入到/导入失败/存档失败）。
5. **注册**：`index.html` 引入 `i18n/en-US.js`；`sw.js` PRECACHE 79 → **80**。

## 三、测试与校验

- 回归测试 +1（45 → **46**）：全局 `t` 暴露、zh 模板插值、en 模板译文、en 未收录回退中文、
  语言包注册、切回中文；
- 全绿：`check:version` 0.3.8 ｜ `check_ui`（PRECACHE 80）｜ `lint` ｜ `validate:story` 210 ｜
  `regressions` 46 ｜ `story` 294/294 ｜ `browser` 9/9（其中「角色头像」用例首跑 flaky，
  单跑与复跑均通过）。

## 四、设计取舍与后续

- **为何只改 `ui/20_saves.js` 作示范**：带变量 toast 分散在 ~10 个 UI 文件；`ui/**` 共享
  全局作用域、`t()` 可见，但逐处改造收益（en 译文前）有限、风险分散。故先示范最常用模块，
  其余调用处按需迁移（模式统一为 `t('模板', {vars})`）。
- **后续**：① 逐步迁移其余带变量 toast；② 补全 en-US 译文与设置页语言切换入口；
  ③ 评估 `story/` 剧情文本抽取（量大，建议单独里程碑）。
