## 二、发现的错误与修复（4 项）

### 1. 巡检工具硬编码浏览器路径（必崩级，已修）

`verify-endings` / `inspect-apps` / `playthrough` / `quick-call` / `quick-narrator` 五个 v0.7.6 新脚本全部写死
`executablePath: '/root/.cache/ms-playwright/chromium-1243/chrome-linux/chrome'`——换机器、换 Playwright 版本即
`executable doesn't exist` 崩溃（本环境安装的是 chromium-1208，5 个脚本全部起不来）。

**修复**：新增 `tools/browser.mjs` 统一启动，按优先级回退：
`PW_EXECUTABLE_PATH` > `PW_CHANNEL` > 系统 Chrome > Playwright 自带 Chromium；7 个巡检脚本全部接入。

### 2. App 巡览盲区——假象通过（已修）

`ui/24_app_unlock.js` 的 openApp 拦截器对未解锁 App 只 toast 不打开。巡览脚本不校验目标屏，
**groups / endings 实际停留在上一个 App 的内容上，却被记录为 OK**（v0.7.6 文档「28/28 打开」的结论部分不成立）。
且拦截器按规则实时计算、不看 `state.appsUnlocked`，仅置解锁标记无效。

**修复**：巡览前补真实解锁条件（`flags.group_created_group_neon`、`endingSeen` 一条记录）+
active 屏校验，不相等记 `BLOCKED`。修复后 28/28 真实打开。

### 3. dock 栏被挤出滚动区（已修）

App 全解锁（28 个）后主屏 grid 超出屏幕，`.home-dock` 为流内 flex 项被推到滚动区外——后期玩家必须滚到
最底部才能使用 Dock（day1 仅 8 个 App 时无此问题，所以一直没暴露）。

**修复**：`position:sticky;bottom:8px` 吸附底部；`qa-shots.mjs` 增加 dock 可见性断言
（实测 top=815 / bottom=889 / inViewport=true）。

### 4. 主屏日期硬编码中文（已修）

`widget-date` 直接拼 `${month}月${date}日`，英文模式不翻译。

**修复**：改 i18n 模板 `{m}月{d}日`（en 显示 `7/15`，两包同步新增，94→95 key 校验通过）；
`i18nchange` 监听补 `updateTimeDisplay()`，切语言即时刷新。

另修 `quick-call.mjs` 改造时误删的 `fs` import（lint error）。

## 三、澄清的假阳性（不是缺陷）

| 现象 | 结论 |
|---|---|
| 桌面视口会话截图为空 | 开局消息**逐条异步到达**（首条约 1.5s），320ms 截图太早；qa-shots 已改为等 1.8s |
| 相册巡览 WARN「text=4」 | 照片网格天生少文字，5 张图正常渲染；判定口径加 `imgTotal`（有图不算空） |
| App 图标显示「□」 | 图标是 emoji 字符（💬📞🌈），沙箱 Linux 缺 emoji 字体；真机（iOS/Android/桌面）正常 |
| 英文模式通知条仍中文 | 通知是 5 秒临时挂件、切语言时已在屏上；影响极小，不做重渲 |
| `openApp('home')` 无效 | openApp 本就没有 home 分支（home 经返回键/锁屏进入），脚本误用，已改 `showScreen('home')` |

## 四、优化方向（按优先级）

### P1（下轮建议）

1. **静态 HTML 文本英文化**：index.html 里各 App 标题（通讯录/礼物商城/主题壁纸…）、隐私页、设置页标签、
   天气挂件「霓城 · 28°C 多云」等均未走 i18n——英文模式大面积中文残留。建议加 `data-i18n` 属性 +
   启动时/切语言时统一扫描替换，与既有 `t()` 机制并行。
2. **部署工作流合并**：三条部署工作流（自有服务器/Pages/HF）各自 `npm ci` 重复安装，可抽 reusable workflow
   或测试工作流统一构建产物、其余只上传。

### P2

3. **覆盖率爬坡**：engine_progress 71.4% / engine_save 70.0% / engine_content 72.0% 三个最低模块补直测。
4. **iOS Safari 走查**：`backdrop-filter`、`position:sticky`、SW 行为在 iOS 的表现（无实机，至少 BrowserStack/真机抽查）。
5. **`getDateLabel().full` 的 i18n**：备忘录/朋友圈时间戳/存档摘要存的是中文 full（如「7月15日 星期三」），
   动态组合无法枚举翻译——需在显示层用 month/date/weekday 字段重拼（同 v0.7.4「中文快照+显示层翻译」模式）。

### P3

6. `HF_TOKEN` 改细粒度（仅该 Space 写权限）；nginx 补 CSP/X-Frame-Options。
7. HF Space 分享卡片 OG 图（dist/index.html 的 og:image 需绝对地址）。
8. itch.io 上架、ui/ ESM 化（旧候选未动）。
