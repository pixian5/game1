## 2. 最关键发现：结局在 day8–10，内容却按 21 天排布

三条线的结局分别在 **day8 / day9 / day10** 触发，而框架与内容按 21 天设计。

### 2.1 day11–21 的内容在主线通关中不可达

- 旧 day12–21 事件、新 day9/day11 事件，在主线玩家身上都不会出现。
- `run-luci` 的 `firedKeys` 中，`day9_*` / `day11_*` **一条都没有**。
- `run-shenyan` 同样没有 day9/day11。

### 2.2 新增线内事件大多选线前或结局后

| 新增事件 | 设定时间 | 实际结果 |
|---|---|---|
| `day4_shenyan_gallery_note` / `day4_luci_street_photo` / `day4_jiangyu_rehearsal` | day4 | 路线选择在 day6–7，**已过时，不可达** |
| `day5_shenyan_afterhours` / `day5_luci_darkroom` / `day5_jiangyu_market` | day5 | 同上 |
| `day6_shenyan_archive` / `day6_luci_print` / `day6_jiangyu_close` | day6 | 视选线时刻，**多数不可达** |
| `day7_shenyan_review` | day7 | 沈线可达（实测触发） |
| `day7_luci_walk` / `day7_jiangyu_song` | day7 20–21 点 | 陆线/江线结局在 day9，部分被跳过 |
| `day9_*` / `day11_*`（6 条） | day9/11 | **结局在前，全部不可达** |
| `day5_solo_window` | day5 | 选线在 day6–7，**不可达** |

### 2.3 真正可达的新增内容只有通用事件

三条线实际触发的新增事件：

- `day4_rain_walk`（通用）
- `day5_susu_lunch`（通用）
- `day6_city_after_rain`（通用）
- 沈线额外：`day7_shenyan_review`

也就是说：**新增 13 条主事件中，主线玩家平均只看到 3–4 条**。

---

## 3. 根因

1. **路线选择在 day6–7**（`route_choice_night` 链 + 开幕式），而线内事件设在 day4–5。
2. **结局判定由最终选择直接触发**（`__shenyan_end_judge` 等），没有等待到 day12/21；`advance_day` 链累计到 day8–10 即结束。
3. **21 天框架与 8–10 天主线不匹配**：day11 之后的内容只对「不推进主线、自行逗留」的玩家可见。

---

## 4. 修正建议（按优先级）

### P0-1 延长主线到 day14+

- 在每条线的最终选择前插入 `advance_day` 链（day10 → day14），中间挂 day10–14 的日常/线内事件。
- 或在 `computeEnding` 触发点加 day 门槛（<day12 不判定），并补过渡事件。
- 验收：三条线通关天数 ≥ day14；`day9`/`day11` 新增事件在 `firedKeys` 中出现。

### P0-2 线内事件时间对齐到选线之后

- 把 `day4_*`/`day5_*`/`day6_*` 的线内事件改为 **day7–day9**（选线后、结局前），或改用 `inRoute:true` + 时间窗口在选线后触发。
- 通用事件可保留在 day4–6。
- 验收：每条线触发 ≥3 条自己的线内事件。

### P0-3 solo 线同步调整

- `day5_solo_window` 移到 day7+；solo 链（`route_solo_*`）之后补 2–3 条 day8–13 独行事件。
- 验收：solo 线触发 ≥3 条 solo 专属事件，通关天数 ≥ day12。

### P1-1 数值校准

- 沈线实测好感 15，恰好触发 HIDDEN；auto 事件固定 +2 会加速阈值。
- 建议 auto 事件改 +1，或 HIDDEN 阈值提高到 18–20；用 `balance-report` 复核三条线。

### P1-2 未读过载

- 独行线实测未读突增 10 条，建议加「一键已读 / 群聊折叠 / 未读上限提示」。

### P1-3 测试补强

- 新增断言：三条线 `firedKeys` 必须包含各自的 `day7–day14` 事件；通关天数 ≥ 设定值。
- 现有 294 项剧情测试未覆盖「新增内容是否可达」，这是本次实测才暴露的盲区。

---

## 5. 结论

- **运行质量没有问题**：三条线 0 错误、0 失败请求，结局与图鉴正常。
- **内容利用率存在系统性浪费**：新增 13 条主事件，主线玩家平均只能看到 3–4 条。
- 下一步不应继续「按天补内容」，而应 **先把主线跨度延长到 day14+，并把线内事件重排到选线之后**；否则新增内容仍会是「写了但玩不到」。
