## 二、总体判断

工程底子好于同体量个人项目：剧情与引擎分层清晰、校验器齐全、PWA 可用、测试覆盖核心链路。
问题不在"能不能跑"，而在**边界处的健壮性、资源效率和长期维护成本**。按影响面归为五类：

### A. 安全与健壮性（P0）

1. **存档导入 → DOM 注入面**：聊天/群聊预览、群名、记忆碎片标题/含义等
   少数 `innerHTML` 拼接了来自 `state` 的文本，未经 `escapeHtml`。正常剧情数据可信，
   但导入 JSON 存档时文本可被构造；CSP 能挡住内联脚本，仍可能造成 UI 覆盖/钓鱼链接。
2. **CSP 元标签含 `frame-ancestors`**：该指令在 meta 中无效，控制台有告警；
   应由服务器头实现（本机不部署，本轮改为清理告警，服务器配置列入后续）。
3. **存档失败路径**：已有内存回退、`saveFailed` 事件与回归测试，但导入/配额提示
   可以更明确；本轮保持并补注释，不改写存档格式。

### B. 性能与资源（P1）

4. **相册网格加载 900×900 原图**：网格实际显示约 121×121，5 张原图 691KB；
   应生成 360×360 缩略图（约 100-150KB 总量），详情页再加载原图。
5. **未使用的壁纸被预缓存**：`assets/wallpapers/default.jpg`（109KB）无任何引用，
   仍被 SW 预缓存；移出 PRECACHE（文件保留给生成器）。
6. **头像 512×512 用于 32-80px**：体积可再降，但当前 174KB 总量尚可，列入后续观察。
7. **49 个脚本请求**：无构建步骤是有意取舍，PWA 缓存后收益明显；本轮不合并，
   避免牺牲可维护性。
8. **图片属性**：补充 `decoding="async"`、`width/height`，降低解码阻塞与布局抖动。

### C. 可维护性（P1）

9. **死代码 `app.js`**：v0.1.7 拆分前的完整副本，3,489 行 / 149KB，未被加载，
   且保留旧版 `getPhotoArt` 等过时实现；删除，避免误改与搜索干扰。
10. **共享工具放错文件**：`escapeHtml` / `nl2brEscaped` 定义在相册 UI 文件，却被
    通知、朋友圈、备忘录等文件使用；迁移到最早加载的 `ui/00_shell.js`。
11. **check:ui 只管引用存在**：不检查资源体积、缩略图配套、manifest 图标、JS 内
    资源字面量；扩展为资源门禁，防止后续美术接入失控。
12. **ESLint 宽松**：`no-unused-vars` 关闭；有 147 条 warning（多数是跨文件全局函数
    的误报）。本轮不强行收紧，只清理真实无用参数。

### D. 可访问性与体验（P2）

13. `maximum-scale=1, user-scalable=no` 禁止缩放；改为允许缩放 + `viewport-fit=cover`。
14. 无 `:focus-visible` 统一焦点样式；键盘用户定位困难。
15. 无 `prefers-reduced-motion` 适配；锁屏提示、徽章、来电等动画无法关闭。
16. Dock 图标无可见文字（`.app-name` 被隐藏），屏幕阅读器只读到 emoji；
   返回键 `‹`、关闭键 `✕` 也缺少可读标签。
17. `100vh` 在移动端动态工具栏下会跳动；补 `100dvh` 与安全区内边距。
18. 假状态栏会被读屏读取；标记 `aria-hidden="true"`。

### E. 测试与内容（P1/P3）

19. 缺少"全部 App 可打开且无脚本错误"的冒烟测试，冷门界面只靠人工。
20. 缺少存档导入注入回归测试。
21. 缺少资源预算门禁（单张照片/头像/缩略图体积、缩略图配套、manifest 图标存在）。
22. 内容侧：独行线止于 day14；无 i18n；头像/照片偏程序化插画；属后续里程碑，不在本轮。

## 三、本轮执行方案（v0.2.7 全局质量优化）

### P0（必须）

- 转义聊天/群聊预览、群名、记忆碎片、遭遇/闪回选项等状态文本；
- 增加"恶意存档导入"E2E，断言 DOM 不生成注入元素、全局变量未被触发；
- 清理 CSP meta 中无效的 `frame-ancestors`；
- 删除 `app.js`。

### P1（本轮完成）

- 照片生成器新增 360×360 缩略图 `assets/photos/thumbs/`，相册网格改用缩略图，
  详情页保持原图；E2E 断言两者分别加载；
- 移除 `default.jpg` 的 PRECACHE 项；
- 图片补 `decoding="async"` 与宽高；
- `escapeHtml` / `nl2brEscaped` / `mergeOptionEffects` 迁到 `ui/00_shell.js`；
- 扩展 `check_ui.js`：JS/manifest 资源字面量存在性、照片/缩略图/头像体积预算、
  每张照片必须有缩略图、manifest 图标存在；
- 新增"全部 App 冒烟"E2E（逐屏 `openApp`，断言无 pageerror、恰好一个 active screen）。

### P2（本轮完成，低风险项）

- viewport 允许缩放 + `viewport-fit=cover`；
- `100dvh` 回退与状态栏/头部安全区内边距；
- 统一 `:focus-visible`；`prefers-reduced-motion` 降级；
- 为返回/关闭/Dock 图标补 `aria-label`，假状态栏 `aria-hidden`。

### 非目标（明确不做）

- 不做服务器部署、不改 nginx；
- 不合并脚本、不引入构建工具；
- 不改存档格式与剧情逻辑；
- 不重做头像/照片美术（视觉里程碑已交付）；
- 不展开 i18n、类型化、day15+ 内容（后续 M2/M3）。

## 四、验收标准

- 全量 `npm run test:all` 全绿，E2E 从 7 条增至 9 条；
- check:ui 输出资源预算与缩略图配套检查，PRECACHE 数量同步；
- 首屏相册网格网络体积显著下降（5 张缩略图总量 <150KB）；
- 无 CSP 控制台告警；键盘焦点与 reduced-motion 可用；
- 文档三件套 + README/索引更新；中文提交并推送三远端。
