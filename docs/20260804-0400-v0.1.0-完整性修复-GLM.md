# v0.1.0 完整性修复

## 修复范围

- 存档导入改为白名单状态重建：限制数组、文本和数值范围，拒绝未知槽位，重新生成摘要与时间，避免恶意字段进入渲染层或破坏引擎状态。
- 本地存储配额或写入失败会明确返回失败；终局状态会立即写入自动存档。
- 事件调度使用运行时排队集合去重，关系临界事件不再因提前标记 `firedEvents` 而丢失。
- 梦境、梦魇、约会和朋友圈回复都增加了完成态保护；梦魇仅在玩家选择后才应用效果并标记完成。
- 结局正文、图鉴和计算规则统一为 17 项；路线分支使用同一个结局 resolver，普通、坏、隐藏和真结局均有可达条件。
- 所有收藏品加入明确获得路径；每日任务改为按当前游戏日检查，连续塔罗改为真正的连续日期。
- 首页可纵向滚动；读档/重开会清除临时 UI 定时器、来电和选择状态；回忆选择会调用专用 resolver。
- 玩家编辑器在重渲染时保留输入，性格问答改为先撤销旧答案再应用新答案。
- 导入状态相关的动态文本均经过转义，页面加入 CSP；朋友圈与日记输入设置长度上限。

## 验证

`node test_regressions.js` 覆盖本次关键回归：恶意/畸形存档、终局持久化、临界事件、幂等、梦魇、每日边界、收藏路径和存储写入失败。
