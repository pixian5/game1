# 霓虹心事 · v0.9.2 day4–5 内容补齐

> 版本：0.9.1 → 0.9.2
> 执行：CodeArts · 2026-11-18

---

## 1. 目标

修正 day4 仅 1 条、day5 为 0 条时间事件造成的节奏断点，并让时间事件支持按具体路线过滤。

## 2. 实现

### 2.1 引擎：`trigger.route`

`engine.js` 的 `checkTimeEvents` 与 `_checkTimeEventsForRange` 新增：

```js
if(evt.trigger.route && evt.trigger.route !== this.state.route) continue;
```

支持 `shenyan` / `luci` / `jiangyu` / `solo`，未选线时不触发。

### 2.2 新增事件（`story/01b_day45.js`，6 条主事件 + 12 条回复链）

| 事件 | 时间 | 路线 | 选项影响 |
|---|---|---|---|
| `day4_rain_walk` | day4 09:00 | 通用 | 理性 / 独立+情感 |
| `day4_shenyan_gallery_note` | day4 14:00 | shenyan | 好感 +2 / -1 |
| `day4_luci_street_photo` | day4 16:00 | luci | 好感 +2 / +1 |
| `day4_jiangyu_rehearsal` | day4 20:00 | jiangyu | 好感 +2 / +1 |
| `day5_susu_lunch` | day5 12:00 | 通用 | 主动 / 独立 |
| `day5_solo_window` | day5 19:00 | solo | 独立 / 情感 |

每条均带 2 选项、性格/好感 effects、reply 文案与后续回复事件。

### 2.3 双语

新增 `i18n/story-en-translations-5.js`，覆盖上述事件的 48 条文本（消息、prompt、选项、reply）。

### 2.4 校验与工具

- `validate_story.js`：新增 `trigger.route` 合法值校验；day4/day5 事件数低于 2 时给出警告。
- `sw.js`：预缓存加入两个新脚本。
- `index.html`：加载新剧情与英译文件。
- `tools/browser.mjs`：`PW_CHANNEL=none` 时使用自带 Chromium（与 `playwright.config.js` 一致）。
