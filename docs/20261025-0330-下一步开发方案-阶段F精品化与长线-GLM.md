## F2 T 轨道技术债清偿（3 轮，长期收益最大）

1. **ES Modules 化**（先手）：
   - story/ → `export const STORY`（一个入口 index.js 聚合）；engine 混入改 import；ui/ 保持全局
     （改动面最小方案：只有 story + engine 侧模块化，`<script type="module">` 加载）
   - 收益：测试直接 `import`（弃 vm 沙箱）→ c8 覆盖率立即可用 → 盲区可视化
2. **test_story 假时钟**：注入 `_now()` 抽象（engine 已集中 `_setTimeout`，改造成本低），
   294 断言从 ~2 分钟降到秒级、消除 v0.1.9/v0.5.4 两次踩过的超时抖动
3. **PhoneEngine 拆职责**：SaveManager（存档/清洗/迁移）与 EventScheduler（队列/定时器）
   先拆出组合对象（保持 prototype 方法转发，调用面零改动）
- 验收：c8 报告接入 CI（引擎行覆盖 ≥60% 起步）；test:story 全程 <30s；全部测试绿
