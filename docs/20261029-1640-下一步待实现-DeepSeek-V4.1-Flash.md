## 部署链路可继续优化的点

1. **三平台产物一致性校验**：目前三条部署工作流各自 `npm ci`，重复约 3 次安装；
   可考虑抽成一个 reusable workflow，或在测试工作流里统一构建、其他两个只做上传。
2. **Space 首屏缓存**：`.static.hf.space` 与自有服务器的 SW 缓存互相独立，
   版本切换时用户可能短暂看到旧缓存；可在页面加「有新版本」提示条（已有 PWA 逻辑可复用）。
3. **分享卡片**：HF Space 页面用的是 README front matter，不含 OG 图；
   若要社交分享预览，需在 `dist/index.html` 保留 og:image 的绝对地址（当前是相对路径）。
