# 《霓虹心事 · 林夏的手机》玩法详解

> **版本**：v0.1.4 · **类型**：手机模拟器 + 文字剧情冒险（都市情感悬疑）
> **视角**：第一/第三视角可切换 · **存档**：4 槽位 + 导入导出 JSON

---

## 一、整体定位

游戏不是传统对话框，而是**模拟一部完整的智能手机**。玩家扮演刚到霓城工作的策展新人 **林夏**，通过操作手机上的 30+ 个 App 推进剧情、养成角色、收集线索。每个 App 都是一个独立的玩法入口，相互关联形成完整生态。

**核心创新点**：
- 时间是真实推进的（玩家可观察到手机状态栏、锁屏时间变化）
- 多个男主**并发**发消息，**已读不回**会触发延迟对话（followup）
- 电话不接会进语音信箱，邀约不答会过期
- 玩家自主决定何时解锁下一个节点

## 三、剧情推进核心机制

### 1. 消息队列（最重要的玩法）

引擎内置 **`InteractionQueue`** 模块（见 [interaction_queue.js](interaction_queue.js)），管理所有进行中的聊天事件：

| 字段 | 含义 |
|------|------|
| `id` | 唯一 ID（`消息_时间戳_随机数`） |
| `type` | message / call / encounter / route_choice / narrator_choice 等 |
| `eventId` | 关联的剧情事件 ID |
| `dueAt` | 计划触发时间戳 |
| `messageId` / `choice` | 关联的消息或选项 |

**关键行为**：
- 消息发送前会**模拟打字**（按文本长度计算 0.7~2.2 秒）
- 玩家**不回复**会触发 `followup` 延迟推送（NPC 主动追问）
- 多次已读不回可触发"已读不回"成就（30 秒阈值）
- 自由输入模式可自行打字回复，触发个性化效果

### 2. 时间系统

- **游戏内时间**：第 N 天 + 当天分钟数（0-1440）
- **真实日历**：起始 7 月 15 日（周三），自动推算星期
- **时间推进方式**：
  - `advanceTime(minutes)`：手动推进分钟数；跨度 > 1 小时会**枚举所有中间小时**以防漏触发事件
  - `advanceToNextDay(hour)`：跳到次日指定小时，触发夜间梦魇检查
- **跨时间触发**：`checkTimeEvents` / `checkIntel` / `checkInvitations` / `checkFlashbacks` / `checkHoliday` / `checkEasterEggs` 每小时扫描

### 3. 事件类型详解

| 事件类型 | 作用 |
|----------|------|
| `message_batch` | 一组消息按延迟依次发送；可选 `then` 后续 |
| `call` | 来电事件；25 秒未接 → `missed` + 语音信箱 |
| `photo_unlock` / `music_unlock` | 解锁相册/音乐 |
| `note_add` / `calendar_add` | 写入备忘录/日历 |
| `moment_post` | 自动发布朋友圈 |
| `dream` | 触发梦境（带选项） |
| `advance_time` / `advance_day` | 推进时间 |
| `route_choice` | 路线选择（4 选 1） |
| `ending` | 触发结局（支持动态计算） |
| `encounter` | 偶遇/赴约剧情屏 |
| `group_message_batch` | 群聊消息 |

|------|------|------|---------|

| **陆辞** | 自由摄影师 | 青梅竹马、暗恋十年 | 九年又一百八十二天；旧学校银杏 |
| **江屿** | 雾港酒吧调酒师 | 前乐队主唱、孤僻 | 写给妹妹的《夏》：B 面从未公开 |
| **苏苏** | 大学闺蜜 | 八卦王、情报网 | 拉"霓城小分队"群；提供关键情报 |
| **narrator** | 旁白 | — | 用于系统提示、梦境、选项等 |

### 2. 四条路线 × 四种结局 + 真结局

| 路线 | GOOD | BAD | NORMAL | HIDDEN | 关键选择 |
|------|------|-----|--------|--------|---------|
| **沈砚之** | 未完的画作 | 镀金的笼 | 画框之外 | 五年前的她 | `shenyan_choice`: confront / endure |
| **陆辞** | 九又二分之一 | 未送出的底片 | 镜头之外 | B 面歌词 | `luci_choice`: accept / miss |
| **江屿** | 雾散之后 | 最后一首歌 | 雾港常客 | 夏的另一面 | `jiangyu_choice`: stay / leave |
| **独行线** | 霓城独行 | 空房间 | 独立策展人 | 第四种可能 | 是否选"谁都不回" |
| **真结局** | 霓城无事 | — | — | — | 独行 + 解锁 ≥60% 成就 |

**路线进入**：游戏第二天深夜，系统弹出"夜深了，先回谁的消息？"，玩家选择 4 条路线之一。

**结局判定算法**（见 [story.js:2131-2153](story.js#L2131-L2153)）：
- 收集了对应路线的**关键信物** + 关键选择正确 → HIDDEN 结局
- 否则根据 `goodCount` / `badCount` 比较 → GOOD / BAD
- 都不满足 → NORMAL

## 五、好感系统（三轴化）

### 1. 综合好感 vs 三轴好感

v0.0.15 起，好感分为**三层**：

```
综合好感 affection[charId]      → 关系阶段门槛
     ├── 亲密度 closeness        → 共同经历
     ├── 信任度 trust            → 愿意敞开心扉
     └── 暧昧度 tension          → 心跳瞬间
```

旧 `effects.affection{charId: n}` 按 50%/30%/20% 自动折算到三轴；新 `effects.affectionDetail{charId:{closeness,trust,tension}}` 可精细驱动。

### 2. 三轴阶段名

| 阶段 | 亲密度 | 信任度 | 暧昧度 |
|------|--------|--------|--------|
| 1 | 点头之交 | 戒备 | 平淡 |
| 2 | 熟悉 | 信赖 | 微澜 |
| 3 | 知己 | 交心 | 心跳 |
| 4 | 生死之交 | 托付 | 炽热 |

### 3. 关系阶段（独立系统）

```
关系阶段关系阶段[charId]  从低到高阶段，从陌生到托付，
                         随综合好感提升自动晋升
```

## 六、性格画像系统

每次对话选项都标注 6 维性格倾向加成：

| 维度 | 含义 |
|------|------|
| `active` | 主动出击 |
| `passive` | 被动接受 |
| `rational` | 理性思考 |
| `emotional` | 感性跟随 |
| `independent` | 独立自主 |
| `dependent` | 依赖他人 |

**性格 X/Y/Z 过高** 会触发：
- **男主视角场景**（通关后解锁）反映他眼中的你
- **隐藏成就**（如 `three_routes`、`solo_path`）
- **梦魇**（见后）

**最深向人物塑造**：`Profile` App 实时显示主角人格雷达图。

## 七、地点与偶遇系统

通过 🗺️ 出行 App 前往 5 个地点：

| 地点 | 偶遇 |
|------|------|
| 🏠 家 | 苏苏视频、翻梦境笔记 |
| 🎨 砚美术馆 | 深夜空展厅偶遇沈砚之 |

| 🌃 天台 | 陆辞拍夜景 |

每个地点有**偶遇池**，包含条件函数（`s => s.day >= 2 && ...`）。满足条件时进入该地点随机触发，单次游戏可多次触发但 `once:true` 的只触发一次。

## 八、互动系统

### 1. 电话系统
- 触发：`call` 类型事件
- 接听：进入通话界面，显示脚本（hearing 点 next 推进）
- 不接：25 秒后自动 missed，**进语音信箱**（可回放解锁成就）
- 通话记录在 📞 电话 App 里查

### 2. 邀约系统
- 三位男主各有一条邀约（画室 / 旧学校 / 雾港首唱）
- 触发条件：好感 ≥ 2~3 + 第 3 天 +
- 接受 → 触发专属剧情 + photos；拒绝/超时 → 扣好感
- **超时 120 秒** 自动 `missed`

### 3. 闪回（闪回五年前）
- 满足特定好感 + flag 触发（三轴达 4 + 拿到特定情报）
- 进入独立时间线，揭示角色过去
- 完成后获得**回忆碎片** + 照片

### 4. 朋友圈
- 主角可主动发朋友圈（带 emoji 配图）
- 男主点赞/评论 → 可回复互动
- 苏苏情报会揭示朋友圈互动

### 5. 群聊 "霓城小分队"
- 第 3 天由苏苏创建
- 沈砚之/陆辞/江屿在其中吃瓜
- 玩家选择潜水中立 vs 全员 +1 vs 沈陆 -1

### 6. 情报系统
- 苏苏基于好感度 + 剧情进度主动推送情报
- 例如：`intel_shenyan_ex`（沈砚之与陌生女人会面）
- 玩家选择相信/调查/无视 → 影响对应 flag

### 7. 回忆杀
- 解锁相册照片后**自动触发**回忆杀
- 三个选项对应不同的回忆碎片（shard）
- 凑齐 3 个碎片触发成就 `dream_walker`

## 九、梦境系统（v0.0.16）

### 1. 普通梦境
- 由 `dream` 事件触发
- 醒来后选项影响**性格和心情**

### 2. 梦魇（nightmare）
触发条件（满足其一）：
- 任一男主 `tension=0` 且 `closeness<3` → 触发 `nightmare_lonely`（空房间）
- 任一男主 `trust<closeness` 且 `tension≥10` → 触发 `nightmare_betrayal`（陌生人）

梦魇效果：
- 扣除 1-2 点某项性格
- 强制设置次日心情
- 解锁后玩家选择"记录/倾诉/继续睡"决定后续走向

🌙 梦魇录 App 查看所有已触发梦魇。

## 十一、每日玩法循环

### 1. 每日任务（3 个 / 天）
从 9 个模板中随机抽 3 个：

| 模板 | 奖励（金币） |
|------|------------|
| 回复任意男主消息 | 30 |
| 抽一次塔罗 | 20 |
| 给男主送礼物 | 50 |
| 切换心情 | 15 |
| 写内心独白 | 25 |
| 发朋友圈 | 35 |
| 前往新地点 | 40 |
| 接听/拨出电话 | 30 |
| 尝试解谜 | 45 |

**连续 3/7/14 天** 完成全部任务可领**连胜奖励**（含 `stamp_first`、`postcard_neon` 等收集品）。

### 2. 塔罗占卜（每日 1 次）
- 22 张大阿尔卡那精选
- 正位/逆位 → 今日运势 + 类型化提示（encounter/affection/dream/ending_hint 等）
- 连续 3 天抽 → 解锁成就 `tarot_believer`

### 3. 心情记录
- 心情类型 10 种：开心/平静/纠结/低落/决意/不安/沉思/孤单/疲惫/坚定
- 不同心情影响后续对话语气（`moodEffects`）
- 体验 5 种以上 → 解锁 `ink` 主题
- 4 种以上 → 解锁成就 `mood_explorer`

### 4. 内心独白（日记）
- 每天可写一段内心独白
- 连续 7 天 → 隐藏彩蛋 `egg_diary_7`

### 5. 约会（每周 1 次 / 每男主）
每位男主每周可约会 1 次（7 天冷却）：
- 沈砚之：午后茶会 / 画室参观
- 陆辞：旧楼天台 / 旧学校银杏
- 江屿：深夜看海 / 排练室

约会完成影响三轴好感，可能解锁照片。

## 十二、男主视角与真相结局

### 1. 男主视角（通关后解锁）
通关某男主 GOOD 或 BAD 结局后，解锁对应男主视角 App：
- 可看到 3 个关键场景的**内心独白**
- 玩家以男主身份做选择，观察同一剧情的另一面
- 每次选择都对应一句 `innerVoice`（内心独白）

### 2. 真相结局
每位男主都有一个**真相结局**（仅在 HIDDEN 结局中触发）：
- 揭示他们没说出口的秘密
- 例如：沈砚之五年前就在美术馆看到你；陆辞的《夏》B 面写的是另一个林夏

## 十八、具体玩法建议

### 新手入门（第一天）
1. 滑动解锁 → 进入主屏
2. 等待苏苏消息（`intro_susu`）→ 选择回复
3. 入睡触发梦境
4. 第二天清晨：沈砚之消息 → 陆辞重逢消息 → 选路线
5. 期中可领取"霓城首日戳"和"霓城夜景明信片"

### 中期目标（第二天~第五天）
- 推进好感度 ≥ 3 触发苏苏情报
- 接受邀约（拒绝会扣好感）
- 前往 5 个地点触发偶遇
- 解锁 3 张以上照片
- 收集 3 个梦境碎片

### 终局路线（路线确定后）
- 收集对应路线的关键信物（`memento_pen` / `evidence_letter` / `evidence_lyrics`）
- 触发闪回章节
- 在关键选择做出正确选项
- 达成 GOOD 或 HIDDEN 结局

### 全结局通关
- 5 路线 × 4 结局 + 真结局 = 17 结局
- 至少需要 5 次完整游玩 + 1 次独行线
- 配合观赏模式可快速刷
