### 发现的真问题：SSH 私钥抄错了一个字符

旧文档里第 4 行是 `dzAsK/3g`，正确应为 `dzAsp/3g`（`K` 与 `p` 一个字符之差）。
这种错误**肉眼极难发现**，因为 base64 看起来都差不多，但会导致密钥完全无法使用。

**教训：任何私钥/令牌写进文档后，必须用工具验证，不能靠复制粘贴的自觉。**
验证私钥的方法：

```bash
ssh-keygen -y -f 提取出的私钥文件   # 能派生公钥就说明格式和内容都对
diff 提取出的私钥 原始私钥文件       # 逐字节比对
```

### 发现的真问题：Hugging Face 令牌失效

令牌返回 401 `Invalid username or password`。
Space 站点本身仍在线（HTTP 200，v0.9.0），只是无法再上传。
已在文档里如实标注"已失效需重签"，并说明不要反复重试。

**这类"看起来还能用其实已失效"的凭据最危险**，
接手的 AI 会浪费大量时间排查。必须在交付时标注实测状态。
