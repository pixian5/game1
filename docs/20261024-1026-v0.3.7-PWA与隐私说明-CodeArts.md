## 一、目标

补齐安装体验与合规信息：manifest 增加 screenshots/shortcuts、新增隐私与数据说明页、
E2E 覆盖隐私页可达。

## 二、改动

### 1. 隐私与数据说明页 `privacy.html`（新增）

纯静态页（深色霓虹风格，与游戏一致，含 CSP），声明：

- **存档**：仅存本机 `localStorage`，不上传；可导出 JSON 备份；
- **错误上报**：仅向**自有服务器**发简短摘要（错误信息+位置+版本号），**不含**存档/聊天/
  个人信息/设备标识，带 30s 节流、静默失败（与 `pwa.js` 现状一致，非新增行为）；
- **不做**：无账号、无第三方追踪/广告/统计 SDK、不出售数据；
- **离线缓存**：Service Worker 仅缓存游戏文件。

入口：`index.html` 的「智能提示」设置 App 底部加「隐私与数据说明」链接（`target="_blank"`）。

### 2. manifest.json 增强

- `screenshots`：3 张真实截图（锁屏 / 主屏 / 消息），`assets/screenshots/*.jpg`，
  780×1688（390×844 @2x，JPEG q82，62/93/43KB）；
- `shortcuts`：桌面长按快捷「开始游戏」→ `./index.html`。

### 3. sw.js

PRECACHE 78 → **79**（新增 `./privacy.html`；screenshots 体积合计约 198KB，**不入预缓存**，
由 manifest 安装时按需获取，避免离线包膨胀）。

### 4. E2E

`smoke.spec.js` 新增第 9 条：隐私页可访问、标题含「隐私」、正文含关键声明（localStorage /
不包含 / 不经过任何第三方）、返回链接可见。E2E 8 → **9**。
