# 《霓虹心事 · 林夏的手机》Seed 开发方案

> **版本**：v0.1.5（基于现有 v0.1.4 规划）  
> **类型**：手机模拟器 + 文字剧情冒险（都市情感悬疑）  
> **当前状态**：核心引擎 + 序章~开幕式剧情已跑通，共通线基础可用，大量系统在 story.js 已定义但 UI/逻辑未实现  
> **目标**：补齐所有玩法系统，打磨剧情细节，达到可完整游玩全结局的状态

---

## 一、现有剧情完整梳理

### 1.1 核心设定

- **主角**：林夏，24岁，刚到霓城砚美术馆工作的策展新人
- **核心玩法**：模拟智能手机操作，通过消息/电话/朋友圈/相册推进剧情，玩家自主决定回应时机
- **主题**：城市孤独、自我成长、爱情选择，三条感情线 + 一条独立成长线

### 1.2 主要角色

| 角色 | 身份 | 性格标签 | 核心秘密 | 代表色 |
|------|------|----------|---------|--------|
| **沈砚之** | 砚美术馆主理人 | 温柔腹黑、控制欲强、完美主义 | 五年前就见过你，画了你五年却没说出口 | #7a5cff 紫 |
| **陆辞** | 自由摄影师 | 青梅竹马、阳光开朗、暗恋十年 | 从高一就喜欢你，拍了你九年，准备了一百多封没寄出的信 | #4ade80 绿 |
| **江屿** | 雾港酒吧调酒师/前乐队主唱 | 孤僻沉默、创伤未愈、才华横溢 | 五年前天台见过你，写了五年《夏》却从未公开；妹妹也叫林夏 | #c084fc 紫 |
| **苏苏** | 大学闺蜜 | 八卦王、情报中心 | 保护你，掌握所有人的秘密 | #fbbf24 黄 |

### 1.3 剧情时间线（已设计完整）

#### **序章：抵达霓城（第1天 22:30）**
1. 苏苏发来消息关心，玩家选择回复方式（影响初始性格）
2. 入睡触发第一夜梦境：「梦·高三的教室」→ 获得第一个梦境碎片
3. 收集：霓城夜景明信片、霓城首日戳

#### **第一天（第2天）：报到与重逢**
1. **08:00** 沈砚之发消息要求九点报到，强调"讨厌不守时"
2. 沈砚之发朋友圈：夏季展开幕预告 → 朋友圈互动（点赞/评论影响好感）
3. **陆辞重逢**：认出你是九年未见的青梅竹马，约晚上吃饭
4. **雾港酒吧**：陆辞带你去江屿的酒吧，解锁霓城夜景照片
5. 陆辞发朋友圈：霓城夜景摄影 → 朋友圈互动
6. **江屿登场**：请你喝第一杯酒，加好友，深夜打来电话
7. 通话中江屿提到写了一首歌叫《夏》，歌词里的人也叫林夏
8. 解锁音乐《夏》，江屿发朋友圈：酒吧驻唱动态
9. 入睡触发第二夜梦境：「梦·空白的画廊」
10. 收集：开幕式工作证、雾港首杯券

#### **第三天：沈砚之的考验**
1. **10:00** 沈砚之点名让你盯下周开幕式，玩家选择回应（勇敢/犹豫/质疑）
2. 陆辞提醒你"离沈砚之远点，他看人的眼神像在估价"
3. 苏苏拉群「霓城小分队」→ 群聊修罗场互动
4. 地点偶遇系统开放：可去 家/美术馆/雾港/天台/街头 触发偶遇
5. 三位男主陆续发出邀约（好感≥2~3时触发）
6. 苏苏情报网启动：根据好感度推送三个男主的秘密情报
7. 入睡触发第三夜梦境：「梦·没有观众的舞台」

#### **开幕式当天（修罗场）**
1. **18:00** 沈砚之叫你去展厅，沈砚之发朋友圈公开感谢你
2. 陆辞要给你拍工作照，两位男主同时在场 → 玩家首次情感倾向选择
3. **夜深天台**：江屿也在天台，"累的时候适合看灯" → 天台近距离接触
4. 解锁天台夜景照片
5. **路线选择之夜（23:00）**：三个人同时发来晚安消息，你回谁决定进入哪条线：
   - 回沈砚之 → 沈砚之线
   - 回陆辞 → 陆辞线
   - 回江屿 → 江屿线
   - **谁都不回** → 独行线（真结局线）

## 四、技术实现要点

### 4.1 事件驱动架构保持
- 所有剧情节点用 STORY.events 定义，通过 `then: 'nextEventId'` 串联
- 选项 effects 统一应用：`affection`/`personality`/`flags`/`thenEvent`
- 用 `_setTimeout` 统一管理所有定时器，newGame/load 时 `_clearAllTimers` 清理

### 4.2 存档兼容性
- state 新字段在 defaultState() 加默认值
- 大版本变化用 save_migrations.js 迁移
- 所有运行时临时状态（pendingInteractions等）不持久化，读档后重建

### 4.3 UI 开发约定
- iOS风格手机框，所有App图标在主屏网格排列
- 每个App是一个全屏div，通过screen状态切换显示
- 消息气泡左（对方）右（我方）对齐，头像+名字颜色用 characters 里的color
- 朋友圈用卡片流，图片方形/圆角
- 电话全屏：来电滑动接听/拒接，通话界面大头像+脚本文字
- 梦境/闪回/结局用特殊全屏样式（暗色+渐入文字）

### 4.4 关键函数需要补全/检查（在engine.js中）

```javascript
// 需要确认存在/补全的每小时/每天检查函数
advanceTime(minutes)          // 已存在，确认跨小时枚举所有中间事件
checkTimeEvents()             // 检查节日、梦魇、生日等
checkIntel()                  // 检查苏苏情报触发条件
checkInvitations()            // 检查邀约超时miss
checkFlashbacks()             // 检查闪回触发条件
checkAchievements()           // 每次effects后检查成就解锁
checkRelationshipStages()    // 好感变化后检查阶段晋升
checkNightmares()             // 入睡前检查梦魇
checkPuzzleUnlocks()          // 收集线索后检查谜题可解
```

### 4.5 数值平衡建议
- 单条路线总好感获取约12~15点（刚好满4阶段"心意"）
- 选项好感：普通+1，关键选择+2，礼物1~2，约会+3~4
- 每日任务金币：30~50，礼物价格80~350，平衡攒钱/送礼节奏
- 邀约超时扣好感-2~-3，不能重开（体现"错过就是错过"的真实感）
