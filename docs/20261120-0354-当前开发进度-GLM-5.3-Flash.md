### 三、修复 P0：一个请求杀死账号服务（v0.9.9 → v0.9.10）

`server/index.mjs` 的 `decodeURIComponent(url.pathname)` 遇到 `/%` 这类非法编码
会抛 URIError，穿透 http 回调成为 uncaughtException 直接杀死进程。
修复前实测：一个 `curl /%` 即可让服务全挂（远程拒绝服务）。
Instabox 线上不崩仅因网关拦截，不经网关的环境（自有服务器）会原样暴露。

修复：解码 try/catch 返回 400 + 进程级 uncaughtException 兜底 +
API 设备会话解码保护 + 3 条回归用例。版本升 **0.9.10**。
