## 二、修复的既有问题

1. **4 条死 flag 清零**（剧情校验器 7 条警告全部清零）：
   - `midnight_call`：`answerCall` 在凌晨 3 点接电话时写入（达成成就「深夜来电」）；
   - `ghost_msg_triggered`：新增剧情事件链 `ghost_msg_5y`（第 4 天凌晨 2 点，陆辞的一条迟到五年的消息）；
   - `_weather`：新增每日天气系统 `_updateWeather()`（每 5 天第 3 天为雨天，确定性伪随机），「雨天」氛围层首次真正生效；读档时按天数重算；
   - `_solo_hidden`：删除从未写入的备用条件引用。
2. **收集品重复发放去重**：`postcard_neon`（序章唯一）、`stamp_first`（`day2_morning` 序章完成唯一发放点，与收集柜说明一致）、`ticket_bar`（雾港酒吧剧情唯一）；连胜奖励改为金币（3 天 200 / 7 天 600）；节日「抵达霓城纪念日」「《夏》首唱纪念日」改为金币奖励（引擎 `checkHoliday` 新增 coins 支持）。
3. **存档性能优化**：`getAllSaves()` 增加内存缓存（此前每次调用都重读 localStorage 并对 4 个槽位全量规范化，UI 与自动存档高频触发）；写档成功同步缓存、失败作废缓存、其他标签页改动（storage 事件）自动失效。
4. **睡眠漏触发修复**：`advanceToNextDay` 原本只检查落点时刻，现在补查睡眠跨过的全部中间小时（`_checkTimeEventsForRange`）——凌晨触发类事件（如幽灵消息）不再漏。

## 三、新增功能

1. **WebAudio 音效系统**（`audio.js`，零依赖合成）：
   - 消息提示 / 来电铃声 / 按键点击 / 收集与成就音效，默认开启；
   - 主题环境音（BGM，极简琶音循环，随 7 套主题切换音组），默认关闭；
   - 首次用户手势解锁 AudioContext（遵守浏览器自动播放策略）；
   - 开关入口：音乐 App 内「🔊 音效 / 🎵 环境音」，持久化到 localStorage；
   - 接入点：`showNotif`、`showIncomingCall`、全局点击委托、`itemCollected`、`achievementsUnlocked`、主题切换。
2. **主题真实壁纸**：6 套主题壁纸由 `tools/generate_wallpapers.py` 程序化绘制（多层辉光 + 星点 + 暗角 + 胶片噪点，1170×2532），叠加在原 CSS 渐变之上（图片缺失自动回退渐变）；「深夜」主题保持纯黑。可随时重跑脚本再生成。
3. **PWA**：`manifest.json` + `sw.js`（静态资源 cache-first 离线可玩，页面 network-first）+ `pwa.js` 注册；图标由 `tools/generate_icons.py` 绘制（霓虹心形，192/512/1024-maskable + 180 apple-touch-icon）；`check_version.js` 新增 `sw.js CACHE_VERSION` 与 VERSION 的一致性校验。
4. **在线部署**：GitHub Pages（`.github/workflows/deploy.yml`，push main 自动部署），地址 https://pixian5.github.io/game1/

## 五、遗留注意事项

- `story/18_patches.js` 是历史增量语句（`STORY.events['xxx']=...`）集中地，新剧情建议直接写进 `01_events` 等对应文件，不要再叠补丁；
- `ui/` 文件共享全局词法作用域：新增顶层 `const/let` 前先确认文件间无重名（合并 `cat ui/*.js | node --check` 可拦截）；
- 发版流程：改 `VERSION` → 同步 `package.json` / `package-lock.json` / `index.html`（标题、meta、全部 `?v=`）→ **`sw.js` 的 `CACHE_VERSION`** → `npm run check:version` 一键拦截。
