# v0.1.4 交互队列与测试基础设施

## 本次变更

- 将路线选择、旁白选择、偶遇和来电统一为可并发持久化的 `pendingInteractions` 队列。
- 保留 `pendingInteraction` 作为旧存档和旧 UI 的兼容镜像，按优先级同步当前交互。
- 新增 `SaveMigrations`，将 v2 单例交互存档迁移到 v3 队列，并补齐延迟任务字段。
- 关闭偶遇时显式取消对应队列项，避免剧情停留在不可继续的状态。
- 增加 Node 回归测试、完整剧情测试、Playwright 浏览器烟测和 GitHub Actions CI。

## 模块边界

- `story.js`：只读剧情与配置数据。
- `interaction_queue.js`：交互队列的插入、查找、删除和兼容镜像同步。
- `save_migrations.js`：存档版本迁移，不负责业务字段校验。
- `engine.js`：游戏状态、事件调度和领域逻辑。
- `app.js`：DOM 渲染与用户交互适配。

## 验证方式

本地浏览器烟测使用 Playwright 的系统 Chrome channel，避免重复下载浏览器；CI 使用 Ubuntu Chromium 安装步骤。完整剧情链路当前为 `294/294`，回归测试和 3 个浏览器烟测均通过。
