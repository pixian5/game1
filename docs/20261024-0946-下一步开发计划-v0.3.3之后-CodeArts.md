# 下一步开发计划（v0.3.3 之后）· CodeArts

> **For agentic workers:** 本计划按「阶段 → 任务 → 版本」组织，每一步结束后都应可独立
> 验证（`npm run test:all` 全绿）并推送。任务级步骤用复选框 `- [ ]` 跟踪。
>
> **Goal:** 把《霓虹心事 · 林夏的手机》从「M1 视觉完成 + M3 日常完成（v0.3.3）」推进到
> **体验收尾 + 海外发表就绪**。
>
> **Architecture:** 纯前端原生 JS（无构建）；`story/` 为纯数据层、`engine*.js` 为状态与
> 调度、`ui/` 为视图；所有校验/测试由 Node 脚本 + Playwright 覆盖，`tools/` 为本地资产生成。
>
> **Tech Stack:** 原生 HTML/CSS/JS、Node 测试脚本、Playwright E2E、Python+PIL（素材）、
> ESLint、Service Worker（PWA）。

## Global Constraints（全局约束，逐字沿用项目约定）

- **版本**：每轮源码修改 `+0.0.1`，**满十进一**（v0.3.3 → v0.3.4 → … → v0.4.0）；升版
  一律 `python3 tools/bump_version.py`，五处同步（VERSION / package.json / package-lock.json /
  index.html / sw.js CACHE_VERSION），并以 `npm run check:version` 为准。
- **门禁**：每轮结束必须 `npm run test:all` 全绿（check:version + validate:story + check:ui +
  lint + test:regressions + test:story + test:browser）；E2E 无系统 Chrome 时用缓存 chromium
  的外部临时配置，**不得改提交进仓库的 `playwright.config.js`**。
- **文档**：每轮产出 docs 三件套（当前开发进度 / 下一步待实现 / 技术文档）+ README
  「当前开发进度 · 下一步待实现」+ `文档索引.md` 同步。
- **提交**：中文 commit，推送到 `origin`（atomgit）。**推送凭据**：`ag` 的 access_token
  不能用于 `git push`；截至 v0.3.3，可用于 `git push` 的是 `xRF8cXTx…` 这一类 PAT。
- **数据铁律**：新增日常/通用事件必须「纯消息、无 choice、无 effects」；`trigger` 现支持
  无 / `soloOnly` / `inRoute` 三态（未来可加 `route`）；每条新事件补对应回归断言。
- **零第三方外发**：错误上报只允许发自有服务器，本地存档不外发。

- [ ] **Step 1: 写失败测试** —— 在 `test_regressions.js` 末尾加：
```js
test('v0.3.4: 三个谜题均提供至少 2 级提示且可判题', ()=>{
  const e = engine();
  const ids = ['puzzle_shenyan_office','puzzle_luci_locker','puzzle_jiangyu_song'];
  for(const id of ids){
    const p = e.story.puzzles[id];
    assert.ok(p, id + ' 存在');
    assert.ok(Array.isArray(p.hints) && p.hints.length >= 2, id + ' 提示 >= 2 级');
    assert.ok(p.answer, id + ' 有答案');
  }
});
test('v0.3.4: 结局判定矩阵——solo 四态可区分', ()=>{
  const e = engine();
  const mk = f => { const s = e.newGame() || e.state; Object.assign(e.state.flags, f); return e.state; };
  assert.equal(e.story.computeEnding(mk({solo_independent:1}), 'solo'), 'solo_good');
  assert.equal(e.story.computeEnding(mk({solo_accept:1}), 'solo'), 'solo_normal');
  assert.equal(e.story.computeEnding(mk({}), 'solo'), 'solo_bad');
  e.state.collected = new Array(10).fill('x');
  assert.equal(e.story.computeEnding(mk({}), 'solo'), 'solo_hidden');
});
```
