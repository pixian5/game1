# v0.7.5：部署到 Hugging Face Space（2026-10-29 16:40 · DeepSeek-V4.1-Flash）

## 一、目标

把游戏部署到抱脸（Hugging Face）平台，作为 GitHub Pages 之外的第三个公开入口。

## 二、关键结论：静态 Space 的域名与产物

1. **Space 类型**：`sdk: static`（纯静态托管，免费、无需 Docker、无需后端）。
2. **直连域名不是 `xxx.hf.space`**：
   - 应用真实地址是 **`https://<user>-<space>.static.hf.space/index.html`**
   - `https://<user>-<space>.hf.space/` 会返回 404（该域名给 Docker/Gradio Space 用）
   - Space 页面内的 iframe 才是 `...static.hf.space/index.html`
   - 排查办法：抓 Space 页面 HTML 里的 `<iframe src="...">`
3. **`/` 是 302 跳 `/index.html`**，属正常行为，不是配置错误。

## 三、实现

### 3.1 上传内容：必须用 `dist/` 而非仓库根目录

仓库根目录是 61 个独立脚本（开发态零构建），直接传上去会让浏览器串行发 61 次跨网络请求
（v0.4.7 实测线上首载 18s）。因此复用已有构建 `tools/build_bundle.mjs`：

- 61 个脚本按 `index.html` 顺序合并成 `dist/bundle.js`（683KB）
- `dist/index.html` 只引用 1 个脚本
- `dist/sw.js` 预缓存清单同步换成 `./bundle.js`
- 其余静态资产原样复制，`dist` 合计 3.66MB / 51 文件

### 3.2 新增文件

- **`.github/workflows/deploy-hf.yml`**：push main 后自动构建 + 上传
  （`npm ci` → `check:version` → `validate:story` → `build_bundle` → `hf upload`）
- **`deploy/hf-space-README.md`**：Space 卡片元信息（front matter：标题/emoji/配色/简介/license），
  由工作流复制为 `dist/README.md` 后上传
- **GitHub Secret `HF_TOKEN`**：已用 `gh secret set` 写入，供 Actions 使用

### 3.3 首次手动部署（已完成）

```bash
hf repos create xbzsb/neon-heart --repo-type space --sdk static --exist-ok
node tools/build_bundle.mjs
rsync -a --exclude '.DS_Store' dist/ /tmp/hf-space/
cp deploy/hf-space-README.md /tmp/hf-space/README.md
hf upload xbzsb/neon-heart /tmp/hf-space . --repo-type space
```

## 五、经验

1. **静态 Space 用 `.static.hf.space`，不是 `.hf.space`**。看到 404 先别改配置，
   去 Space 页面抓 `<iframe src>` 拿真实地址。
2. **必须上传构建产物**。仓库是"零构建"开发态，61 个脚本直接托管会慢到不可用；
   `dist/` 的 bundle 方案同时服务自有服务器和 HF 两个平台。
3. **`hf` CLI 已升级到 2.x，子命令变了**：`huggingface-cli` → `hf`，
   `repo create` → `repos create`，`--space_sdk` → `--sdk`，且 2.x 没有 `hf api`。
4. **本机 `~/.local/bin/hf` 是坏的符号链接**（指向已删除的 `/Users/x/.hf-cli/venv/bin/python`）。
   本次用 `uv venv /tmp/hfvenv` + `uv pip install "huggingface_hub[cli]"` 临时装一份，
   避免污染系统 Python。若长期使用，建议重建 `~/.hf-cli/venv` 或改用 `uv tool install`。
5. **Token 走 Secret，不落仓库**：`HF_TOKEN` 已写入 GitHub Secrets；
   注意该 Token 是 write 权限，泄露可改写全部 Space。
