# v0.3.1：男主线中后期日常（M3.3）

> 2026-10-24 06:39 · CodeArts

## 一、背景与动机

独行线在 v0.2.9/v0.3.0 补齐了 day15-21 的中后期日常，而三条男主线（沈砚之 / 陆辞 /
江屿）在 day15+ 仍**没有日常内容**——四线出现不对称。

根因：`trigger` 只有 `day` / `hour` / `soloOnly` 三个字段，`soloOnly` 表达的是"仅非男主线"，
**没有"仅男主线"的条件**，所以男主线专属日常此前无从表达。

## 二、引擎改动（engine.js）

为两处时间事件判定（`checkTimeEvents` 与 `_checkTimeEventsForRange`，同口径）新增
`trigger.inRoute` 条件：

```js
if(evt.trigger.inRoute && !inRoute) continue;   // 仅已进男主线时触发
```

其中 `inRoute = !!this.state.route && this.state.route !== 'solo'`（既有定义不变）。
至此 trigger 支持四种场景：无（通用）/ `soloOnly`（独行线及未定线）/ `inRoute`（男主线）。

## 三、新增男主线中后期日常（story/01_events.js）

三条男主线**共用中性文案**（不特指某位男主，避免三线分叉带来的文案爆炸），带塔罗 hint 变体：

| 事件 | 触发 | 内容 | hint 变体 |
|---|---|---|---|
| `day15_route_work` | day15 10:00 | 开幕筹备期，忙碌中的留白（narrator） | rational / affection / memory |
| `day16_route_city` | day16 20:00 | 城市夜色，回味关系中那句话（narrator） | memory / affection / dream |
| `day17_route_three` | day17 09:00 | 三周小结：关系比预想更近（narrator） | affection / rational / luck |

铁律延续：纯消息、无 choice、无 effects，避免侵入男主线结局段。事件总数 203 → **206**。

## 五、维护提醒

- 新增男主线/独行线专属日常：分别用 `trigger.inRoute:true` / `trigger.soloOnly:true`，
  并保持纯消息；两条件天然互斥，同 day/hour 可并存而不会互相干扰；
- `trigger` 现有四态（无 / soloOnly / inRoute）；如需"限定某一位男主线"，需再扩展
  `trigger.route` 字段并同步两处判定。
