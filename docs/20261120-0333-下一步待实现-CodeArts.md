## P0：账号服务上公网

当前容器 8095 已完整运行，但公网静态入口（`oh.sbbz.tech` / GitHub Pages / HF Space）
仍是纯静态，账号按钮会显示“服务不可用”。要公网可用，需要：

1. 在公网服务器用同一仓库启动 `server/index.mjs`，`NH_SITE_ROOT` 指向 `dist/`。
2. Nginx 把 `/api/` 反代到 Node，静态仍由 Nginx 发；或整站直接反代 Node。
3. HTTPS 下确认 `X-Forwarded-Proto` 传递正确，Cookie 才会带 `Secure`。
4. 验证：注册→上传→刷新→第二设备登录→恢复→注销。

> 注意：`dist/` 构建若只含前端，账号 UI 仍在；但 `server/` 不能进静态根。
