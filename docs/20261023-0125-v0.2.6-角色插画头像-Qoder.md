## 二、头像生成（新增 tools/generate_avatars.py）

- 输出 `assets/avatars/<id>.jpg`，512×512；3 倍超采样绘制后 LANCZOS 缩小，保证线条平滑。
- 体积：`shenyan` 42,890B · `luci` 43,751B · `jiangyu` 46,948B · `susu` 44,502B，
  均低于 100KB 预算（JPEG q90 自适应）。
- 绘制管线（自底向上）：
  1. 背景：双段渐变 + 径向辉光 + 双层散景（大光斑 + 细小高光点）+ 光带 + 角色专属符号；
  2. 后发 → 脖颈 → 衣领/躯干 → 面部 → 五官 → 前发 → 配饰 → 轮廓光；
  3. 面部用参数化轮廓（`face_points`）生成下颌收窄的平滑脸型，阴影/高光按面部蒙版合成；
  4. 收尾：bloom → 轻柔焦 → 电影调色 → 暗角 → 胶片颗粒。

  - **沈砚之**：紫色美术馆画框、侧分短发、细框眼镜、高领黑衣、银胸针；

- 中途踩坑：脖颈最初在躯干之后绘制，导致长脖子盖在衣领外；改为「后发 → 脖 → 躯干 →

## 六、经验

1. **头像要看实际尺寸**：512px 原图能看出很多粗糙处，但 32–44px 下真正决定辨识度的是
   发色、服装色块和背景色，按实际尺寸做预览比盯大图更有效。
2. **图层顺序是人物插画的地基**：脖颈/衣领/头发的前后关系错一层，就会变成长脖子或
   头发穿过衣服；先定层级再调细节。
3. **CI 缓存 key 要跟依赖版本走**：不能用 package-lock 全文件哈希（版本号每次发版都变），
   用 Playwright 包自身哈希更稳。
