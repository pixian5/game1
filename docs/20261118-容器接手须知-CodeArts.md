## 1. 最重要的事实

1. **容器内数据不持久**：`/workspace` 可能在会话间被清空或回滚。所有有价值的东西必须进入 Git。
2. **每次开工先同步**：

```bash
cd /workspace
rm -rf game1
git clone https://atomgit.com/laotongtian/game1.git
cd game1
# 或已存在时：
git fetch https://atomgit.com/laotongtian/game1.git main && git reset --hard FETCH_HEAD
```

3. **不要依赖本地未提交文件**：测试截图 `qa-shots/`、`.handoff/` 都被 `.gitignore` 忽略，容器重建即丢失。

## 4. 版本与提交规范

1. 每轮必须 `python3 tools/bump_version.py`（自动 +0.0.1 并同步 7 处）。
2. 提交前必须：`validate:story`、`check:ui`、`lint`、`test:regressions`、`test:story` 全绿。
3. 提交身份：`laotongtian <sbxwn@noreply.gitcode.com>`（用 `git -c user.name/-c user.email`，勿改全局）。
4. 三端同步：

```bash
git push <atomgit-URL> main
git push <某远端-URL> main
git push <gitcode-URL> main
```

（远端地址与凭据由用户提供，**不要写进仓库文件**。）

## 5. 内容开发铁律（v0.9.5 踩坑总结）

新增时间事件必须同时满足：

1. `trigger:{ deferWhenBusy:true, day:..., hour:..., route:'shenyan'|'luci'|'jiangyu'|'solo' }`
2. 选项对象加 `auto:true`（氛围事件自动结算，不弹选择），否则会与主线 `choice` 抢占，`test:story` 必挂。
3. 同步 `i18n/story-en-translations-*.js`，并用 `tools/i18n-gap.mjs` 收口到 0。
4. `index.html` 与 `sw.js` 同步新脚本（`check:ui` 会拦截遗漏）。

**不要**把 `pendingMessages` 移出 `_mainChainBusy()` 判定，否则主线消息链会被插入。
