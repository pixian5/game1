## 二、两个踩坑记录

1. **本机 DNS 被代理劫持**：oh.sbbz.tech 在本机解析为 198.18.1.71（fake-ip），SSH 直接被拒。
   `deploy.sh` 用阿里 DoH 解析真实 IP 再直连（若本机解析正常则直接用域名）。
2. **rsync 目录平铺**：多源 rsync 中 `story/`（尾斜杠）会把目录**内容**合并进目标根，
   与 `ui/` 的文件混在一起导致 404；改为不带尾斜杠（`story` `ui` `assets`）传目录本身。

## 三、一键部署

```bash
npm run test:all   # 先跑通全部测试
bash deploy.sh     # rsync 到服务器并自动验证线上标题
```

`deploy.sh` 已入库（端口/路径/密钥路径集中在脚本头部，迁移服务器只改三行）。
SSH 密钥默认用 `/Users/x/ed25519`；如需收敛权限可另发专用密钥放 `~/.ssh/game1_deploy`（脚本自动优先）。
