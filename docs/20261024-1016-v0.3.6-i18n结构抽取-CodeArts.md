# v0.3.6：i18n 结构抽取（B1-a）

> 2026-10-24 10:16 · CodeArts

> 本版为《下一步开发计划（v0.3.3 之后）》**阶段 B 的第一个任务 B1（i18n）** 的第一步。

## 一、目标

海外发表前置：建立**语言包 + 查询/回退框架**，把可枚举的 UI 固定文案集中管理，默认中文
（中文为源，未命中回退原文，不阻塞运行）；`story/` 剧情文本量大，按计划**本版不逐条抽取**。

## 二、改动

### 1. 新增 `i18n/` 框架

- `i18n/index.js`：`I18N.translate(text, vars)`（查当前语言包，未命中回退原文，支持 `{name}`
  插值）、`setLang(lang)`、`getLang()`、`availableLangs()`；默认语言 `zh-CN`。
- `i18n/zh-CN.js`：中文语言包 `window.I18N_PACKS['zh-CN']`，收录 **44 条** UI 固定文案
  （存档/主题/约会/谜题/心情/关系等 toast；中文原文即 key，为 en-US 预留映射位）。

### 2. 接入（零改调用处）

`ui/00_shell.js` 的 `toast()` 内统一翻译：
```js
t.textContent = (typeof I18N !== 'undefined' && I18N.translate) ? I18N.translate(msg) : msg;
```
—— 所有既有 `toast('...')` 自动经过文案层；带变量的动态串（如 `toast(r.reason)`）不匹配
固定文案时回退原文，行为不变。

### 3. 注册

- `index.html`：在 `story/00_core.js` 前引入 `i18n/zh-CN.js` + `i18n/index.js`（带 `?v=`）；
- `sw.js`：PRECACHE 76 → **78**（新增两个 i18n 文件）。

## 三、测试与校验

- 回归测试 +1（44 → **45**）：i18n 查表 / 未命中回退 / `setLang` 切换（无 en 包仍回退）/
  插值 / 语言包注册；
- 全绿：`check:version` 0.3.6 ｜ `check_ui`（PRECACHE 78 项、52 脚本）｜ `lint` ｜
  `validate:story` 210 ｜ `regressions` 45 ｜ `story` 294/294 ｜ `browser` 8/8。

## 四、设计取舍与后续

- **取舍**：`toast()` 内统一翻译 vs 逐处改调用处——选前者（低风险、零侵入、覆盖全部 toast）；
  代价是"带变量的动态串"无法整串翻译，需在调用处改 `t('模板', {vars})` 才能覆盖。
- **后续（B1-b）**：① 把高频带变量文案改为 `t('已购买：{name}', {name})`；② 增 `i18n/en-US.js`
  并做 `setLang` UI 切换入口；③ 视需要再评估 `story/` 剧情文本抽取（量大，建议单独里程碑）。
