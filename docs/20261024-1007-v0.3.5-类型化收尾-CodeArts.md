# v0.3.5：类型化收尾（M3.7 / 计划 A3）

> 2026-10-24 10:07 · CodeArts

> 本版为《下一步开发计划（v0.3.3 之后）》**阶段 A 的第二个任务 A3**。

## 一、目标

`types.js` 此前只有结构性骨架（GameState 仅列 13 个字段、无 Trigger/Ambience/Puzzle 等）。
本版把它补齐为**与 `engine.js defaultState()` 逐字段对齐的权威类型参照**，提升 IDE 悬停与
后续渐进类型化的准确性。

## 二、改动（`types.js`，95 → 247 行）

1. **重写 `GameState`**：由 13 个字段扩展为**覆盖 `defaultState()` 全部字段**（day/minute/
   conversations/callLog/photos/music/... /momentReplies 共 60+ 项），并注明「v0.3.5 起与
   defaultState 逐字段对齐，结构性变更须同步本文件」。
2. **扩展 `GameEvent`**：`trigger` 引用独立 `Trigger`；`messages` 引用 `MessageItem`；
   补充 `groupId`、`ending`、`_compute`。
3. **新增 typedef**：
   - `Trigger`：`day` / `hour` + 可选 `soloOnly`（仅非男主线）/ `inRoute`（仅男主线），
     明确二者互斥、可同日同 hour 并存（v0.2.9~v0.3.3 的日常机制）；
   - `MessageItem`：`text` + 可选 `flavors`（塔罗 hint 文案变体）；
   - `EventEffects`：flags / personality / affection / affectionDetail / collectible；
   - `PuzzleProgress`：`attemptCount`/`solved`/`lastAttempt`；
   - `PlayerProfile`：主角自定义画像；
   - `Ambience`：含 `layerImage`/`layerBlend`（v0.2.7 M1.3 氛围壁纸机制）；
   - `Puzzle`：`clues`（各给 1 位）/ `answer` / `hint` + `hints`（≥2 级，v0.3.4）。

## 四、维护提醒

- **state / story 结构变更时，必须同步 `types.js`**（本文件是类型权威参照）；
- 新增事件触发条件时，先扩展 `Trigger` typedef 再落地；
- `types.js` 不参与运行，但会被 lint 扫描——保持合法 JS 语法（结尾 `if (typeof window ...)`
  占位即为保证是合法模块）。
