## v0.4.6：P1 工程 + 服务器安全

1. **安全响应头**：nginx 下发 CSP（含有效的 frame-ancestors 'none'）/X-Frame-Options DENY/
   HSTS/Referrer-Policy；index.html meta 移除无效的 frame-ancestors。
   **踩坑入档**：nginx 的 add_header 继承规则——location 一旦有自己的 add_header，
   server 级全部失效；location 级 Cache-Control 改用 `expires` 指令后修复。
2. **专用部署密钥 + GitHub Actions 自动部署**：`~/.ssh/game1_deploy`（公钥入服务器
   authorized_keys，私钥进 GitHub Secret `NEON_DEPLOY_KEY`），`deploy-server.yml`
   push main → 轻量校验 → 复用 deploy.sh rsync（workflow 里无需 DoH 解析，直连域名）。
   主密钥 ed25519 不再进任何 CI 凭据。
3. **资源体积预算门禁**（check:ui 第 5 段）：单图 ≤420KB / 单脚本 ≤160KB / 图片总量 ≤3.3MB
