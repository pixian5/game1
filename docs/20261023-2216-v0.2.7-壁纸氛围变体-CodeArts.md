# v0.2.7：壁纸氛围变体（M1.3）

> 2026-10-23 22:16 · CodeArts

## 一、目标（M1.3）

为「雨天雾感 / 夜晚灯海 / 不安暗流」三种氛围生成壁纸变体，随 ambience 自动切换，
叠加在主题壁纸之上；复用并扩展现有 `wallpaperOverlay` 机制。素材走本地 PIL（零外部依赖）。

## 二、素材生成 `tools/generate_ambiences.py`

输出 `assets/ambiences/<id>.jpg`，纯 PIL（无 numpy 依赖）。

| 氛围 | 设计 | 混合模式 | 体积 |
|---|---|---|---|
| `rainy` | 中灰偏亮冷色雾底 + 520 条斜雨丝 | soft-light | 82 KB |
| `night` | 近黑底 + 城市散景光点 + 天际线灯带 + 星点 | soft-light | 62 KB |
| `anxious` | 暗紫红中低灰底 + 6 条扭曲暗流 + 强暗角 + 大噪点 | soft-light | 26 KB |

**分辨率取舍**：首版用与壁纸同规格 1170×2532 生成，rainy/night 达 227/199 KB，超预算。
氛围纹理本质是模糊质感，改为**半分辨率 585×1266**（cover 放大几乎无损），体积降约 4 倍
至 82/62/26 KB，合计 168 KB。这是本轮控制 PWA 预缓存总量的关键。

## 三、合成机制

1. **数据层** `story/17_hints_ambiences.js`：三档氛围新增 `layerImage`（纹理路径）与
   `layerBlend`（background-blend-mode 值）；其余氛围仅有 `wallpaperOverlay` 颜色层。
2. **合成** `ui/18_affection_theme_gallery_dates.js` 新增 `composeWallpaper()`：
   按「氛围纹理 → 主题图 → 主题渐变」拼多层 `--wallpaper-1`，并把逐层混合模式写入
   `--wallpaper-blend`。
3. **样式** `style.css`：`#lock-screen, .lock-bg, #home-screen, .home-bg` 增加
   `background-blend-mode: var(--wallpaper-blend, normal)`，让多层背景真正混合。
4. **触发** `applyThemeToBody()`（ui/18）与 `applyAmbienceToBody()`（ui/20）都调用
   `composeWallpaper()` —— 主题或氛围任一变化都会重新合成壁纸。

背景层顺序（`layers[0]` 在最上）：氛围图(blend) → 主题图(normal) → 主题渐变(normal)。

## 四、关键踩坑：混合模式决定明暗方向

- 初版 `night` 用 `screen`：screen **只会提亮**，结果"夜晚"壁纸反而比白天更亮
  （截图像素统计 lum 39 → 56），语义完全反了。
- 改为 `soft-light`：暗底（night 图 lum≈23）会**压暗**基色、亮光点处提亮 →
  夜晚壁纸整体变暗（39 → 28）且保留灯点，符合语义。
- **教训**：`screen`/`soft-light`/`overlay` 之一是"只增不减"，选错会反转氛围方向；
  视觉走查不能只看"有没有变化"，要看"变化方向对不对"。
