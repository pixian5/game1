# v0.2.3：hint 变体横向扩展 + 独行线 day11+ 日常（2026-10-22 22:47 · Doubao）

## 一、目标

v0.2.2 建立了消息级 `flavors` 变体机制。本版做**横向扩展**：
1. 把变体铺到**群聊**（聚餐现场三场景的苏苏直播开场）；
2. 新增**独行线 day11-14 中后期日常**（此前独行线日常只到 day10），新事件直接按
   hint 设计变体，丰富独行线玩家的中后期内容。

## 二、群聊变体（story/01_events.js）

| 事件 | 消息 | 变体类型 |
|---|---|---|
| group_dinner_scene_hotpot（火锅现场） | 苏苏直播开场 | luck / affection / memory |
| group_dinner_scene_izakaya（居酒屋现场） | 苏苏直播开场 | luck / affection / memory |
| group_dinner_scene_gallery（美术馆现场） | 苏苏直播开场 | luck / affection / rational |

选择三场景各配**第一条直播消息**（其余保持默认）：直播开场是最"现场感"的一句，运势变体
不破坏其余角色台词与效果。群聊消息变体由 `queueGroupMessage` 的 `_flavoredText` 自动生效
（v0.2.2 已支持群聊通道，本轮仅补数据）。

## 三、独行线 day11-14 新日常（纯消息，不带 choice）

| 事件 | 触发 | 内容 | 变体 |
|---|---|---|---|

设计约定（延续 v0.2.1 教训）：
- **全部 `trigger.soloOnly: true`**——只服务未进男主线（含独行线）玩家，三处同口径拦截；
- **全部纯消息、不带 choice**——避免通用事件 choice 抢主线/测试的选择（v0.2.1 回归教训）；
- 不带 effects——纯氛围内容，不干扰三轴数值测试预期。

## 四、测试与验证

- 回归测试 +2：聚餐现场 luck 变体（数据层 + 引擎一致）；day11+ soloOnly 触发（独行线
  触发、男主线不触发、4 事件注册完整）；
- 事件总数 184 → **188**，validate:story 0 错 0 警；
- 全量校验：lint 通过 · test:regressions 30/30 · test:story 294/294；E2E 在 test:all 收尾。

## 五、经验

1. **变体机制横向复用成本极低**：v0.2.2 建好 `flavors` + 双通道注入后，本轮只写数据；
2. **新通用日常的铁律**：soloOnly + 纯消息（无 choice）——从源头避免主线侵入与选择抢跑；
3. 群聊变体选"直播开场"单条而非全员台词，控制文案量的同时保持机制完整可感。
