## 二、实现要点

### 1. applyStaticI18n（i18n/index.js）

```
data-i18n="原文"              → textContent 替换（含子元素的元素跳过，防破坏结构）
data-i18n-placeholder="原文"  → placeholder
data-i18n-title / data-i18n-aria → title / aria-label
data-i18n-href="zh页|en页"    → 按语言切换链接目标（隐私双页面）
```

setLang 时先于 i18nchange 派发调用；启动链路 ui/22_settings.js:86（localStorage → setLang）自动覆盖。
key 与 t() 同机制（中文原文精确匹配、miss 回退原文）。

### 2. 子元素场景处理

tab 含角标（语音信箱 + tab-dot）、按钮含 span 的场景，迁移脚本统一包一层纯文本 `<span data-i18n>`，
静态结构与替换安全兼得。applyStaticI18n 对含子元素元素的跳过是第二道防线。

### 3. localizeDateLabel（P2-5）

```
'7月15日 星期三' → /^(\d{1,2})月(\d{1,2})日(?:\s*星期([一二三四五六日]))?$/ 解析
  → t('{m}月{d}日 {w}', {m, d, w: t('星期三')})  → en: '7/15 Wed'
'7月16日'        → t('{m}月{d}日', ...)          → en: '7/16'
'第3天'/null/非标准 → 原样返回（存档标签不误伤）
```

存档/剧情数据仍存中文 full 快照（v0.7.4 同款「中文快照 + 显示层翻译」模式）。

### 4. 隐私双页面

privacy-en.html 完整英译（保留 `<b>` 加粗结构，避免 textContent 替换破坏正文）；
sw.js PRECACHE、build_bundle 资产清单、check_ui 引用校验（data-i18n-href 管道两值分别校验）同步。
