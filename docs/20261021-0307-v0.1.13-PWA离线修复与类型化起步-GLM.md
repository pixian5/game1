# v0.1.13 PWA 离线修复与类型化起步（2026-10-21 03:07 · GLM）

> 承接 v0.1.12 的工程收尾轮。**本轮抓到一个线上真实故障**：PWA 离线模式此前完全不可用。

## 一、PWA 离线故障修复（高危）

新增「离线重载」E2E 测试后立刻暴露：在线注册 SW → 断网 → 重载，锁屏可达但点击无反应——
**全部 49 个 JS/CSS 离线加载失败**（net::ERR_FAILED × 52）。

根因：页面引用脚本带缓存参数（`story/00_core.js?v=0.1.13`），而 `caches.match(req)` 默认
**严格匹配 URL 含查询参数**——预缓存存的是无参数路径，带 `?v=` 的请求全部 miss。
锁屏看似正常纯属 HTML 初始 class，实际 JS 全没加载（离线打开 = 空壳）。

修复：`sw.js` 静态资源分支改为 `caches.match(req, { ignoreSearch: true })`（忽略查询参数匹配，
这是 `?v=` 版本化资源 + SW 的标准做法）。离线 E2E 5/5 通过。

**教训入档**：v0.1.7 上线 PWA 时只有「在线」用例——凡是「按设计应该工作」的路径，都要有一条
自动化用例钉住它（离线能力拖了 5 个版本才被发现）。
