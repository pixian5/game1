## 一、目标（M3.1）

独行线（真结局线）此前的通用日常只覆盖到 day14（v0.2.3 补齐 day11-14）。本版继续向后
延伸 **day15-18 四条新日常**：半月小结、天气（梅雨季）联动、独处心境、节令（灯河节）
联动，让选择独行线的玩家在中后期仍有稳定、成体系的内容节奏。

## 三、设计要点与约束

- **铁律（延续 v0.2.1/v0.2.3）**：全部 `trigger.soloOnly: true` + **纯消息、不带 choice**、
  不带 `effects` —— 只服务未进男主线的玩家，且不抢占主线选择、不干扰三轴数值测试预期；
- **天气/节令如何"联动"**：经查 `engine.js`，`trigger` 仅支持 `day` / `hour` / `soloOnly`
  三个字段，**没有天气条件位**。因此天气（梅雨季）与节令（灯河节）作为**内容主题**融入
  事件文案，并通过**塔罗 hint 的 flavors 变体**呈现不同当日运势下的口吻差异，而非硬分支；
- **flavors 键**沿用既有 hint 类型（luck / affection / memory / rational / dream），
  由 `_flavoredText` 在私聊通道自动生效，无需改引擎。

## 五、经验

1. **通用日常该往哪找素材**：城市在地感（糖水铺、江边点灯、灯河节）+ 独行线特质
   （一个人也很好）比强行塞剧情更贴合「独行」主题；
2. **"联动"要看清引擎能力边界**：`trigger` 无天气位，天气/节令只能走文案 + 变体，
   硬做条件分支反而会引入不可达事件；
3. 铁律依旧是安全底线：soloOnly + 纯消息，从数据层避免主线侵入与选择抢跑。
