# v0.4.4：三远端同步 + 防御性转义（2026-10-24 15:20 · DeepSeek-V4.1-Flash）

## 一、本轮起因

用户接通 WiFi，要求「把该下载的下载、拉取最新代码」。检查后发现两件事：

1. **本地/gitee/github 都停在 v0.2.6，而 gitcode 已到 v0.4.3，领先 23 个提交。**
   三远端并非自动互为镜像——另一台机器（CodeArts）把 v0.2.7~v0.4.3 全部推到了 GitCode，
   gitee/github 没有跟进。
2. 本地工作区还有一份 **v0.2.6 时期未提交的改动**：删除废弃副本 `app.js`、
   把 `escapeHtml / nl2brEscaped / mergeOptionEffects` 从相册 UI 迁到 `ui/00_shell.js`、
   并给会话预览/群名/日历/音乐/记忆碎片/偶遇与闪回选项补转义。

## 五、经验与避坑

1. **三远端不会自动同步**：每轮开工前先 `git fetch gitee github gitcode` 并
   `git rev-list --left-right --count HEAD...<remote>/main`，确认哪边最新。
   GitCode 是目前实际的主线来源。
2. **未提交改动不能直接 pull**：先用 `git stash -u`，快进合并后再 `stash pop`；
   合并前把 patch 落到仓库外（`/tmp`）做双保险。
3. **转义函数必须放在最早加载的 UI 文件**：拆文件后各脚本共享全局作用域，
   定义在后面的文件里，前面的文件调用时虽然不会报错（调用发生在运行时），
   但一旦加载顺序调整就会踩空，统一放 `00_shell.js` 最稳。
4. **E2E 断言要盯住「正在输入」占位**：会话预览在 `typing=true` 时不显示最后一条消息，
   测试注入后必须先关掉 typing，否则断言读到的是「正在输入…」。
