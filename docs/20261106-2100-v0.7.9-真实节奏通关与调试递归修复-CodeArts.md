## 2. 真实节奏下暴露的缺陷

### D1 调试日志递归导致栈溢出（P1）

`debug.js` 的 `console.error` hook 调用 `error()`，`push()` 又通过全局 `console.error` 输出日志，形成自调用：

```
console.error → error() → push() → console.error → …
```

实测：`RangeError: Maximum call stack size exceeded @ debug.js:191`，并产生 1MB+ 的 `[NeonDebug]` 自引用日志。

**修复**：文件加载时保存 `__origConsoleError/__origConsoleWarn`，`push()` 只调用这两个原始函数，不再经过 hook。

### D2 空选择渲染崩溃（P1）

`showChatChoice(convId, choice)` 直接读取 `choice.prompt`，`choice` 为 `null` 时抛 `TypeError: Cannot read properties of null (reading 'prompt')`（`ui/04_engine_events.js:100`）。真实节奏复验中，群聊的 `showGroupChoice(groupId, choice)` 在 `ui/10_voicemail_groups.js:465` 出现同类异常。

**修复**：两个函数入口均校验 `choice` 与 `options`；无效时隐藏输入栏并返回，不再崩溃。

## 3. 新增回归用例
