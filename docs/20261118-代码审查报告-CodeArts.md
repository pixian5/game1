## 3. 已修复缺陷

### D1（P2）玩家昵称作为 `String.replace` 替换串

- 位置：`engine_progress.js:332`
- 现象：昵称含 `$&`、`$'`、`$1` 等会被当作替换模式解释，输出错乱。
- 修复：替换参数改为函数 `() => p.name`。

### D2（P3）音效与曲目按原型链查找

- 位置：`audio.js:364`、`audio.js:373`
- 现象：`SFX[name]`、`TRACKS[trackId]` 可命中 `constructor`、`__proto__` 等键，导致异常。
- 修复：改为 `Object.prototype.hasOwnProperty.call(...)` 校验。

### D3（P1）脚本关闭 SSH 主机密钥校验

- 位置：`deploy.sh:14`
- 现象：`StrictHostKeyChecking=no` 可被中间人劫持；同时存在 `/Users/x/ed25519` 本机路径回退，跨环境失效。
- 修复：改为 `accept-new`（首次记录、后续校验）；私钥缺失时显式报错退出，支持 `DEPLOY_SSH_KEY` 指定。

### D4（P2）测试配置硬绑定系统 Chrome

- 位置：`playwright.config.js:17`
- 现象：`channel: 'chrome'` 在无系统 Chrome 的环境直接失败（本机即如此）。
- 修复：支持 `PW_CHANNEL`（`chrome`/`msedge`/`none`）与 `PW_EXECUTABLE_PATH`，默认行为保持不变。

### D5（P3）忽略规则未覆盖私钥/凭据

- 位置：`.gitignore`
- 修复：补充 `*.pem`、`*.key`、`*.p12`、`*.pfx`、`id_rsa*`、`id_ed25519*`、`credentials*.json`、`.env.secret`。
