## 一、设计决策（动手前定死，避免返工）

1. **译名约定拼音**，与剧情翻译包（`story-en-translations*.js`）的既有译名表对齐：
   林夏→Lin Xia、沈砚之→Shen Yanzhi、陆辞→Lu Ci、江屿→Jiang Yu、苏苏→Su Su、
   夏夏→Xiaxia、小夏→Xiao Xia、老夏→Lao Xia、夏→Xia、霓城→Nicheng、雾港→Wugang、
   霓城小分队→Nicheng Squad、未知→Unknown、独行线→Solo Route、真结局→True Ending、
   我→Me、你→You。
2. **存档仍存中文 name 快照，显示层走 `t()` 翻译**。语言切换即时生效、无需存档迁移；
   通话记录（`addCallLog`）、结局图鉴派生（`getEndingGallery` 的 `charName`）等数据层
   均不动，只翻显示出口。
3. **专名映射入 UI 包（i18n/zh-CN.js、i18n/en-US.js）**，不入剧情包——i18n 是精确匹配
   （key=中文原文），映射若混进剧情合并包会误伤包含人名的整句。
4. **玩家自定义名不误翻**：`p.name` / `p.nickname` 是用户输入，经 `t()` 的 miss-回退
   语义天然安全——映射外的名字（如「苏念」「Alice」）原样返回，只有映射内名称才被翻译。
5. **模板串变量值要二次过 `t()`**：`translate` 先查 key 再做 `{var}` 替换，变量值不自动
   翻译。正确写法 `t('{char}发来邀约', {char: t(char.name)})`。

实现要点：

- **`t` 单字母全局函数遮蔽**是本轮最大的坑：`ui/03:140`、`ui/10:455`、`ui/17`（任务对象 `t.name`）、
  `ui/18:69/83`（主题对象 `t.name`）等处存在 `const t = ...` / 回调参数 `t` 遮蔽全局翻译函数。
  统一用 `window.t` 或 `ui/10` 既有的 `VMT` 包装器（自带无 i18n 环境回退）规避。
- `story/17` 在 Node 测试沙箱里无 `t`，用 `typeof window.t === 'function' ? window.t : (s)=>s`
  守卫式局部 `_tn`，保证 `test_story.js` 的 `hintR.includes('沈砚之')` 断言（中文默认）不破。
- 显示出口统一补 `escapeHtml`（名字进 innerHTML 的场景）。
