# 下一步开发方案 · 阶段 E「沉浸与出海」（2026-10-25 01:40 · GLM）

> 承接 v0.4.7（D1-D5 全部落地后的新阶段规划）。基于事实核查：
> ① 音乐 App 14 首曲目均为无声元数据（playMusic 只改状态）；② i18n.setLang 无任何 UI 入口；
> ③ 剧情文本总量仅 **5900 字 / 353 节点 + 32 个选项提示**——英文化远比预想可控；
> ④ `state.endingSeen` 已就位，周目系统有现成基础。
> 优先级按「玩家感知收益 ÷ 工作量」排序；每项含验收标准。

## E1 设置中心（1 轮 · 小）

**问题**：设置入口散落三处（音效在音乐 App、观赏模式在任务 App、智能提示在提示 App），
语言切换完全没有入口——i18n 框架空转。

**做法**：
- 新增 `settings` App（主屏图标「设置⚙」）：语言（zh-CN / en-US）、主音量+音乐+音效三滑杆、
  减弱动效手动开关（D1.3 已有 prefers-reduced-motion 检测，补手动覆盖）、
  选项提示/观赏模式开关迁移至此（原入口保留跳转）
- 持久化 localStorage（键 `neon_settings`），AudioSys/i18n/D1.3 全部读该配置
- 验收：切换 en-US 后全部 UI 固定文案变英文、重启保持；音量滑杆实时生效；预算门禁不超

## E2 音频系统二阶（2 轮 · 中 · 感官收益最大）

**问题**：全游戏唯一的声音是提示音+合成琶音 BGM；音乐 App 的《夏》《渡鸦》等剧情曲全是
"假播放"——这是当前最大的感官缺口。

**做法**（保持零素材依赖，纯 WebAudio）：
- **BGM 引擎升级**：从 6 音琶音升级为「和弦进行 + 主旋律 + 打击层」的三层曲式循环；
  7 主题 × 3 氛围（雨/夜/不安）= 分层混合（雨天叠雨声白噪、夜晚降 BPM、anxious 加不协和音程）
- **剧情曲真实化**：《夏》《渡鸦》《海雾》等 5 首剧情曲各写一段 8-16 小节主题旋律（可辨认、可哼唱），
  音乐 App 点播真实出声；剧情触发点（首唱/结局）自动切对应曲
- **场景 sting**：结局/梦魇/邀约/谜题解开各配 2-4 秒短乐句
- 设置中心接音量三分级；隐私页说明更新（纯合成、无第三方素材）
- 验收：静听可区分 7 主题 BGM；音乐 App 播放有真实旋律；E2E 加「音频上下文创建」冒烟
- 备选：若你要真实乐器质感，届时提供免版权曲库再混音（默认不依赖）

## E3 周目系统「二周目」（2 轮 · 中 · 复玩价值）

**基础**：`endingSeen` 已存在；收集品/成就/图鉴天然跨周目（存于 state）。

**做法**：
- 任一结局达成后，结局屏出现「再来一次（二周目）」入口 → newGame 时打 `ngPlus:1` 标记
- **携带项**：收集柜、成就、结局图鉴、塔罗图鉴保留；好感/剧情 flag 清零
- **二周目专属内容**（flag 驱动，6 处）：开场苏苏消息变体（"又来了？这次看仔细点哦"）、
  三人初遇台词各 1 处微调、谜题NPC 提示二周目直接给答案方向、真结局追加 epilogue 事件链
  （「霓城无事」之后的一周：三人的近况消息 ×4）
- 主角档案页显示周目数与全结局达成率
- 验收：二周目可从任意结局进入且携带正确；epilogue 仅真结局二周目可见；validate 零警告

## E4 英文化一期（2-3 轮 · 出海前置）

**数据支撑**：5900 字 / 385 个文本节点——**一期即可覆盖全量**（原以为要按章节分期）。

**做法**：
- 管线：`tools/extract_story_strings.mjs` 扫描 story/ 全部 text/prompt/desc/onSuccess 等
  字符串 → 生成 `i18n/story-en.json`（key=中文原文）；校验器新增「翻译覆盖率」报告（抽取串 vs 包内 key）
- 渲染接入：`appendMessage` / `showChatChoice` / 结局/梦境/邀约等 6-8 个文本出口统一过
  `I18N.translate()`（未命中回退中文，游戏不会坏）
- AI 初翻全量 5900 字 + 人工校对风格表（人名/称呼/语气：沈砚之=Shen Yanzhi、夏夏=Xia）
- CSS 适配英文长词换行与字号（聊天气泡、选项按钮）
- 验收：设置中心切 en-US 后序章→day3 全英文可玩；回退中文处有覆盖率报告追踪；单包 ≤120KB（预算门禁）
