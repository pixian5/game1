## 10. 注意事项

1. **版本规范**：每轮 +0.0.1，必须用 `tools/bump_version.py`；不要手改单处。
2. **发布必须用 `dist/`**：根目录发布会导致首载串行请求 61+i18n 脚本。
3. **工作副本可能被外部回滚**：若出现文件消失或 HEAD 退回旧提交，执行
   `git fetch https://atomgit.com/laotongtian/game1.git main && git reset --hard FETCH_HEAD`，或重新 clone。
4. **调试模式 `?debug=1`** 会挂 hook；生产默认关闭。
5. **长任务用后台执行**（`setsid nohup ... &`）并轮询日志，避免工具超时。
6. 新增 UI 文案必须同时补 `i18n/zh-CN.js` 与 `i18n/en-US.js`，并接入 `t()`；用 `tools/i18n-gap.mjs` 收口。
