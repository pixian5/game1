# v0.3.4：谜题提示链补全 + 结局可达性走查（M3.6）

> 2026-10-24 09:59 · CodeArts

> 本版为《下一步开发计划（v0.3.3 之后）》**阶段 A 的第一个任务 A1**。

## 一、目标

3 个谜题此前只有单条策略提示（`hint` 字符串），遇到卡关时缺乏"分级引导"；同时 17 个结局的
`computeEnding` 分支较多，缺少**判定矩阵**回归，冷门结局有"不可达/误判"风险。

## 二、改动

### 1. 多级提示链（数据 + UI）

- `story/11_collectibles_puzzles.js`：三个谜题新增 `hints:[一级, 二级]`（保留原 `hint` 兼容）；
  - 沈砚之办公室：① 先翻开四条线索 → ② 数字顺序＝线索顺序
  - 陆辞储物柜：① "九年又一百八十二天"是第一个数字 → ② 顺序 年→日→月→事
  - 江屿《夏》歌词：① 碎片数字就是歌词顺序 → ② 按句序 1→2→3→4 排
- `ui/14_collection_puzzles.js`：提示区改为**分级揭示**——首次显示 1 条，每次提交失败
  多揭示 1 条（`showN = min(len, attemptCount+1)`）；无 `hints` 时回退单条 `hint`，向后兼容。

### 2. 结局可达性走查（回归矩阵）

在 `test_regressions.js` 新增两条矩阵断言，钉住判定分支：

- **solo 四态**：无 flag → `solo_bad`；`solo_accept` → `solo_normal`；`solo_independent` →
  `solo_good`；收集品 ≥10 → `solo_hidden`。
- **男主线三态（以陆辞为例）**：`luci_choice=accept`+`luci_confess` → `luci_good`；
  `luci_choice=miss`+`luci_avoid` → `luci_bad`；无 choice → `luci_normal`。

> 说明：`computeEnding` 依赖 `state.flags` / `collected` / `affection` / `achievements` /
> `personality` 多维输入；矩阵测试即"可达性走查"的自动化形态，覆盖隐藏/好/普通/坏四级。

## 四、维护提醒
