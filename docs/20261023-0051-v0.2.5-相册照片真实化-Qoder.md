## 一、目标

落地《下一步开发方案》的 M1.1：用本地 PIL 程序化生成「霓虹城市」照片感素材，替换相册里
5 张 SVG 占位图。验收标准：相册视觉统一、单张 <150KB、`check:ui` 通过。

本轮全程本地生成，无任何下载或联网素材。

## 二、素材生成（新增 tools/generate_photos.py）

- 运行环境：Pillow 12.3.0 + numpy 2.5.3，使用 `/opt/homebrew/bin/python3.14` 执行
  （系统默认 `python3` 为 3.15，未装 PIL；未安装任何新依赖）。
- 输出：`assets/photos/<art>.jpg`，900×900，与 `STORY.photos[*].art` 的 5 个键一一对应。
  方案原写「6-8 张」，但当前剧情只有 5 张照片数据，故按实际内容生成 5 张，后续新增照片
  时在同一脚本追加场景即可。
- 照片感管线（`finish()`）：bloom 高光溢出 → 轻度柔焦 → 色差 → 电影感 S 曲线调色 →
  暗角 → 胶片颗粒；场景内再叠加多段渐变天空、径向辉光、景深光斑、分层天际线、体积光、
  玻璃雨痕等。
- 五个场景：
  - `city`：出租车内视角，高架/车流、层叠楼群、密集散景、仪表台剪影；
  - `rooftop`：天台栏杆、城市灯海散景、月亮、混凝土纹理、前景植物；
  - `album`：木桌台灯、摊开的相册（内页 5 张小照片对应本组素材）、前景散落照片与相机；
  - `studio`：夜晚窗景与月亮、体积光、画架与未完成画布（画布纹理）、画笔/调色盘；
  - `school`：黄昏教学楼（窗灯/钟/台阶）、银杏树与落叶、小径、前景虚化树叶、飞鸟。
- 体积控制：`save()` 从 q86 起每档 −2 自适应压缩，配合 optimize + progressive，
  直到单张 <150KB。

## 五、经验

1. **CSS Grid 的隐式行会拉伸**：容器有富余高度时默认 `align-content:normal` 等价
   `stretch`，只有两行内容会把行距撑开；照片接进来后立刻暴露，需显式 `start`。
2. **绝对定位先看包含块**：`.photo-close` 的 `position:absolute` 一直相对
   `.photo-content`（`position:relative`），不是屏幕；只改 top/right 无法根治，
   把按钮移出该容器才是正确修法。
3. **程序化照片的边界**：这套管线能做出统一色调与镜头感，但仍是风格化插画而非写实摄影；
   若后续要求更高真实度，图像 API 路线留到流量恢复后再评估（方案决策点 ① 不变）。
4. **体积和观感要一起调**：自适应质量对颗粒/散景多的图更敏感；在 <150KB 约束下，
   先降质量档再考虑降分辨率，900×900 在 280px 展示尺寸下仍有余量。
