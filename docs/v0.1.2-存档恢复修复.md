# v0.1.2 存档恢复修复

## 问题

旧版存档只记录 `firedEvents`，没有记录异步消息和链式事件的待执行状态。刷新页面后，开场消息、来电和部分剧情链可能已经被标记为已触发，却没有机会再次执行。

此外，存档规范化时会丢弃会话选项、朋友圈交互配置和群聊选项；继续游戏也固定读取自动档，可能覆盖较新的手动档进度。

## 修复

- 将待发送消息、群消息、链式事件和延迟来电写入存档，并在读档后按剩余时间恢复。
- 对会话/群聊选项和朋友圈配置做白名单恢复，动态评论只从当前剧情配置重建。
- 继续游戏按存档时间选择最新槽位，同一毫秒优先手动档。
- 增加刷新恢复、互动恢复和最新槽位回归测试。
