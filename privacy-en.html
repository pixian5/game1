Privacy & Data

Neon Heart · Lin Xia's Phone · Last updated 2026-11-20

1. Play without an account: local by default

If you do not register, all saves (progress, affection, collection, settings, etc.) stay in your browser storage (localStorage) and are never uploaded. You can export them as JSON or clear browser data to delete them.

2. Optional account and cloud saves

An account is an optional enhancement. Only after you register and sign in may the game upload all four save slots as one package to this project's own server for cross-device sync. While signed out, or before you press “Upload” / enable auto-sync, the server receives no saves.

  • Registration data: username, nickname, password, one-time recovery code. Passwords are stored only as scrypt hashes with random salts, never in plain text; recovery codes are hashed too. No email or phone number is required.
  • Cloud saves: one JSON package covering four slots (progress, affection, collection, settings), plus revision, update time, and a device label.
  • Sessions and security records: browser User-Agent, IP address, sign-in/last-active times, and expiry for each signed-in device; security logs for register, login, password change, upload/conflict, export, and deletion (kept for up to 90 days).
  • Cookies: one HttpOnly, SameSite=Lax session cookie (nh_session) valid for 30 days. No advertising or third-party tracking cookies.

3. Error reporting

When a script error occurs, the game sends a brief summary to this project's own server (error message + location + version) solely for debugging. It contains no saves, chat content, account data, or device identifiers, goes to no third party, is throttled to once per 30 seconds, and fails silently.

4. Your controls

  • Export: while signed in, export a JSON containing your profile, cloud saves, device sessions, and security records.
  • Revoke devices: sign out other devices individually; changing your password signs out all other devices automatically.
  • Delete account: requires your password again. It removes the account, cloud saves, all sessions, and that account's security logs. This cannot be undone. Offline saves in this browser's localStorage are not deleted remotely and can be cleared separately in the game.

5. What we do not do

  • No third-party trackers, ads, or analytics SDKs;
  • No selling or sharing your data with third parties;
  • No background upload of saves while you are signed out.

6. Offline and caching

This game is a PWA and uses a Service Worker to cache its own files for offline play. The cache contains game files only, never your password or cloud saves.
