Privacy & Data

Neon Heart · Lin Xia's Phone · Last updated 2026-10-24

1. Your game data

All saves (progress, affection, collection, settings, etc.) are stored in your device's browser storage (localStorage) and are never uploaded to any server. You can export them as a JSON file for backup within the game, or delete them at any time by clearing your browser data.

2. Error reporting

When a script error occurs, the game sends a brief summary to our own server (error message + location + current version), used solely for troubleshooting. This reporting:

  • contains only the summary above — no game saves, chat content, personal information, or device identifiers;
  • goes to this project's own server and never passes through any third party;
  • is throttled to once every 30 seconds and fails silently, so it never interrupts gameplay.

3. What we don't do

  • No account system; we do not collect your identity information;
  • No third-party tracking scripts, ads, or analytics SDKs;
  • We never sell or share your data with any third party.

4. Offline & caching

This game is a PWA that uses a Service Worker to cache its own files for offline play; the cache contains game files only and none of your personal data.
