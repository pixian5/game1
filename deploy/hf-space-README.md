# 霓虹心事 · Neon Heart

一部会自己响的手机：三个男主同时给你发消息，已读不回会有后果。

- 纯前端（HTML / CSS / 原生 JS），运行时零依赖、无需后端
- 210 个剧情事件 · 17 个结局 · 4 条路线（含独行线真结局）
- 中英双语 · 可安装为 PWA · 离线可玩（Service Worker）

源码：https://github.com/pixian5/game1
