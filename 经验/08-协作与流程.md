# 08 · 协作与流程

> 来源：多模型协作历史、用户直接在对话中下达的指令、禁提事项文档、push_all.sh 实践

## 一、用户最强调的一条：严禁提上架

**这是硬性禁令，违反会严重触怒用户。**

项目处于开发测试阶段，**绝不允许在任何分析、建议、总结、待办清单里
主动提及上架、发布、商店、分发平台、itch.io 等内容**。
只有用户自己先提起时才能讨论。

已写入 `docs/20261118-禁提事项-用户指令.md`。
这条优先级高于其它一切写作习惯（例如"给下一步建议时要全面"）。

## 二、多模型协作是常态

这个仓库先后由 GLM、DeepSeek、Doubao、Qoder、CodeArts、Seed、Qwen、M3、Kimi 等
多个模型改过。因此：

- 看到陌生提交时，**先怀疑是不是更早的自己或并行会话**，
  对照自己写过的计划文档，不要贸然断言"有别人在改"
- 提交信息里带版本号和模型署名，便于追溯
- 每个版本的问题记录写入 `docs/`，命名 `年月日-时分-标题-模型名.md`

## 三、文档规约

1. 文档统一命名 `YYYYMMDD-HHMM-<标题>-<模型名>.md`
2. **写了文档就必须同步更新根目录 `文档索引.md`**，否则等于没写
3. README 只放【当前开发进度】【下一步待实现】摘要，详细内容进 docs，
   README 要指向对应的两个 docs 文件
4. 根目录 `经验/` 存放从 docs 提炼出的做法手册（docs 不一定对，经验要准）

## 四、Git 远端

项目根 `push_all.sh` 会遍历当前已配置的全部远端并检查 HEAD 是否一致。
本仓库当前未配置远端；需要推送时由用户指定目标，AtomGit 等平台单独处理。

```bash
for r in $(git remote); do
  echo -n "$r: "; git ls-remote $r -h refs/heads/main | head -1
done
```

**注意**：
- 不要 force push main
- 提交信息用中文
- `push_all.sh` 必须是纯 ASCII 输出，曾因多字节字符导致 `unbound variable`
- **含真实令牌的文件绝不能提交**，GitHub 会拦截（GH013）并暴露令牌

## 五、版本号规矩

每次改源代码就把版本号加 0.0.1。用脚本改：

```bash
python3 tools/bump_version.py 0.9.7
node check_version.js
```

## 六、修改完成的标准

**不允许"改完就停"**。每轮必须：

```bash
npm run test:all        # 全绿
node tools/build_bundle.mjs
```

线上部署的还要跑 `node tools/live-check.mjs`。
失败就继续修，不能带着失败停下。

## 七、发现可优化点时主动说

用户明确要求：发现能明显提升、优化的方向时**主动告知详情**，
特别是与已有要求冲突时，交给用户决定是否优化。

但注意与第一条的边界：主动建议里**不能碰发布相关内容**。

## 八、代码风格

- 注释用中文
- 回复用详细中文，不用简称
- 英文专有名词后面附中文
- 代码要读起来像周围的代码（命名、注释密度、惯用法保持一致）

## 九、本机操作注意事项

- 运行 Python 程序前先检查项目内虚拟环境，没有就创建并激活
- 不在本机装 MySQL 等，需要数据库就启 Docker
- 做界面操作优先用 computer-use 技能，不要前台点击影响用户使用电脑
- 本机是 M5 / macOS 27，与服务器环境严格区分

## 十、账号功能的测试分层（v0.9.9）

不要把账号逻辑只交给手工浏览器：

1. **API 集成测试**（`server/test_api.mjs`，51 项）：真实进程 + 临时 SQLite，覆盖注册校验、
   CSRF、云存档 revision/冲突/force/超限、双设备踢人、改密、找回码、导出、注销级联。
2. **账号 E2E**（`playwright/account.spec.js`）：注册→找回码→上传→刷新会话→云端恢复→退出→
   找回重置→新密码登录→改昵称→注销，全流程一条用例。
3. **全量浏览器回归**：`test:browser` 用 `--grep-invert "账号与云存档"` 排除账号，
   账号用 `test:account` 单独跑，避免重复执行。
4. `test:all` 串起 API + 账号 E2E + 其余浏览器；容器里记得传 `PW_EXECUTABLE_PATH`。

文档三件套照旧：`docs/` 技术记录 + 当前进度 + 下一步，README 摘要，`文档索引.md` 登记。
