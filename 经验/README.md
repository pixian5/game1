# 经验目录说明

本目录把 `docs/` 下 148 份文档的结论**去重、去错、压缩**成可直接查阅的经验条目。

## 使用原则

1. **docs 不一定是对的**。docs 里包含大量当时的临时判断、中途被推翻的方案、
   以及不同模型互相矛盾的结论。本目录只保留经过验证的部分。
2. **本目录是"怎么做事"的手册，不是"做过什么"的流水账**。
   版本流水看 docs，做事方法看这里。
3. **遇到冲突以代码为准**。本目录写错的地方，请直接改本目录，不要改 docs 历史文档。
4. 每条经验都标注了来源文档，需要追细节时再回去看。
